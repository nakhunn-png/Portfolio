# 맵 개선 검증용 사본

실제 게임(`index.html`, `js/`)은 그대로 두고, 새 지도와 "불 꺼진 마지막 층"을 따로 시험하는 사본이에요.

## 여는 방법
- 게임: `nyamnyam/maptest.html` (더블클릭해도 열려요)
- 층별 전체 지도: `nyamnyam/maptest-preview.html` (주소 끝에 `?id=3`을 붙이면 그 층만 보여요)
- 타이틀 화면 왼쪽 아래 **🧪 검증용** 상자에서 원하는 층으로 바로 갈 수 있어요. "불 끄기"에 체크하면 어느 층이든 어둡게 시작해요.
- 기록은 실제 게임과 따로 저장돼요(저장 키 `nyamtest1:`). 실제 학생 기록에는 영향이 없어요.

## 바뀐 것
**지도 구조(층마다 다른 도면)**
| 층 | 구성 |
|---|---|
| 튜토리얼 | L자 연습실 → 한 번 꺾이는 복도 → 모서리가 파인 연습실 |
| 1층 급식실 | 입구 → 손 씻는 곳 → 넓은 식탁 홀. 북쪽 배식 통로와 동쪽 반납대가 조리실 앞에서 다시 만남 |
| 2층 채소칸 | 세로로 긴 문 쪽 선반, 계단 모양 잎채소 칸, 선반 줄 사이 좁은 통로, 떨어진 얼음 칸, 넓고 얕은 맨 아래 서랍 |
| 3층 우유·고기칸 | 가운데 큰 냉장 설비를 한 바퀴 도는 통로와, 둘레에 붙은 크기가 다른 보관실 6개 |
| 4층 텃밭 | 울타리 친 밭들 사이를 흙길이 잇는 바깥 공간, 물탱크·도구 창고 |
| 5층 시장 | 한 번 꺾이는 큰길에 골목이 입을 벌리고 붙음, 뒷길·뒷창고로 돌아가는 길 |
| 6층 주방 | 좁은 현관 → 집 복도 → 식탁. 개수대·냉장고·가스레인지가 폭이 다른 통로로 이어지고 찬장 창고가 따로 있음 |

- 벽은 바닥 둘레에 저절로 생기고, 그 바깥은 어둡게 칠해서 건물 윤곽이 보여요.
- 가구는 용도에 맞게 벽을 따라 묶어 놓았고 모두 충돌 판정이 있어요. ?가구와 숨는 곳은 되도록 벽이나 가구에 붙여 놓아요.
- 이전 패치의 바닥 무늬·가구 그림·방 안내판·단서 봉투는 그대로 써요.

**불 꺼진 마지막 층**
- 과정의 마지막 층에서 불이 꺼져요. 1시간용은 5층 시장, 2시간용은 6층 주방이에요. 튜토리얼은 해당하지 않아요.
- 주인공 둘레 약 2칸은 밝고, 4칸 밖은 거의 안 보여요.
- 너무 막막하지 않게 쫓아오는 균의 빨간 **!**, 열린 탈출문, 감지기, 탈출문 방향 화살표는 어둠 속에서도 보여요.
- 층을 시작할 때 영양이가 "불이 꺼졌어!"라고 알려 줘요.

**저장 데이터**
- 지도 버전을 4로 올렸어요. 옛 지도로 저장된 "진행 중인 층"은 그 층만 새 지도로 처음부터 다시 해요.
- 이때 "지도가 새로 바뀌어서 이 층은 처음부터 다시 해요. 모은 별은 그대로예요."라는 안내가 떠요.
- 이미 끝낸 층의 별, 완료 기록, 반·번호, 학년군, 과정, 캐릭터, 난이도는 그대로예요.
- 그 층에서 모으던 쪽지 조각, 주운 비누, 들고 있던 아이템, 위치는 초기화돼요.

## 검증한 것
자동 검사(`node maptest/check-maps.mjs`, 7개 층 모두 통과):
- 모든 바닥이 출발 자리와 이어져 있고, 탈출문 앞까지 갈 수 있음
- ?가구 수(튜토리얼 4, 나머지 10), 숨는 곳 수(1, 4), 각 물건 앞에 설 자리가 있음
- 문 안쪽이 가구로 막히지 않음. 복도는 모두 2칸 폭이고, 6층의 의도한 한 칸짜리 틈만 예외
- 막힌 칸은 모두 화면에 그려지는 가구나 물건임(보이지 않는 벽 없음)
- 균 출발 자리와 줍는 것이 바닥 위에 있음
- 균 이동 120초 시뮬레이션에서 벽 안에 들어가거나 5초 넘게 멈춘 균 없음

브라우저에서 실제 게임 코드로 확인:
- 7개 층에서 실제 충돌 이동으로 모든 ?가구·숨는 곳·탈출문까지 걸어가 상호작용 대상이 됨
- 6개 층의 복도 곳곳(층마다 12곳)에서 균이 6걸음 떨어진 곳부터 쫓아와 3초 안에 닿음, 벽 통과 없음
- 1시간용 5층·2시간용 6층에서만 어두워지고, 1시간용 2층·2시간용 5층은 밝음
- 옛 지도 버전 저장을 이어 하면 그 층만 새로 시작하고 1층 별 3개는 남음
- 콘솔 오류 없음

## 아직 확인하지 못한 것
- 터치(가상 조이스틱)로 움직이기. 키보드 입력과 게임 내부 이동 함수만 확인했어요.
- 태블릿·교실 TV 실제 화면 크기에서의 모습과 어둠 효과의 속도
- 문제 풀기 → 쪽지 붙이기 → 탈출까지 한 층을 처음부터 끝까지 손으로 플레이하기
- 아이들이 느끼는 어려움 정도(특히 불 꺼진 층)

## 실제 게임에 넣을 때
`maptest/js`의 `layouts.js`, `map.js`, `game.js`를 `js/`로 옮기고, `ui.js`는 `MAP_VERSION`을 가져오는 줄과 `startPlay`의 바뀐 부분(옛 지도 판별, 불 끄기, 안내 문구)만 옮겨요.
`ui.js`의 검증용 층 바로 가기와 `save.js`의 저장 키 변경은 **옮기지 않아요**.
그다음 README의 묶기 명령으로 `js/app.js`를 다시 만들고 `sw.js`의 `VERSION`을 올려요.
