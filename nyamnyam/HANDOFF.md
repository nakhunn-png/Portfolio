같은 저장소에 다른 프로젝트(대항해시대 교역품 등)가 같이 있다. 커밋할 때 `nyamnyam/` 파일만 `git add` 한다.

## 2. 고친 뒤 꼭 하는 일
1. 묶기: `nyamnyam` 폴더에서
   `npx esbuild@0.24.0 js/ui.js --bundle --format=iife --target=es2019 --outfile=js/app.js --legal-comments=none`
   화면은 `js/app.js`만 읽는다. 분리 소스만 고치면 반영되지 않는다.
2. `sw.js`의 `VERSION`을 하나 올린다(예: `nyam-v20` → `nyam-v21`).
3. 지도를 고쳤다면 `node maptest/check-maps.mjs "<nyamnyam 경로>/js"`로 자동 검사(인자를 빼면 `maptest/js`를 검사한다).
4. 커밋 → `git push origin main` → 1~2분 뒤 `https://nakhunn-png.github.io/Portfolio/nyamnyam/sw.js`에서 새 VERSION 확인.

커밋 메시지 형식: `냠냠 탈출: <바뀐 점>` + 본문 목록 + `Co-Authored-By` 줄.

## 4. 지금 들어 있는 기능(이번 작업분)

**지도**
- 층마다 다른 비정형 도면(`layouts.js`). 바깥은 어둡게, 꺾인 복도, 용도별 고정 가구.
- 방 입구 미닫이문: 주인공·균이 가까이 오면 열림. 주인공이 열 때만 소리(`Sound.door`), 0.4초 쿨다운.
- 지도 구조를 바꾸면 `MAP_VERSION`을 올린다. 진행 중이던 층만 새 지도로 다시 시작하고 별·완료 기록은 남는다.

**난이도 6개**(`DIFFS`, 첫 화면 3개×2줄)

| 키 | 이름 | 목숨 | 균 속도 | 주인공 | 특징 |
|---|---|---|---|---|---|
| `veryeasy` | 🐣 매우 쉬움 | 무한 | 0.54 | 1.725배 | 진짜 쪽지·탈출문 길 안내 화살표(`guide`), 충치쟁이 휴식 1.3배 |
| `gentle` | 🌱 쉬움 | 무한 | 0.6 | 1.15배 | 충치쟁이 휴식 1.3배 |
| `easy` | 🙂 중간 | 무한 | 0.75 | 1배 | 예전 '쉬움'. 키를 바꾸지 않아 옛 저장과 호환 |
| `hard` | 💪 어려움 | 3 | 1 | 1배 | 균 +2 |
| `hell` | 🔥 불지옥 | 1 | 1 | 1배 | 균 +2, 쪽지 문제 틀리면 조각 흩어짐(`scatter`), 거미줄(`webs`) |
| `darkness` | 😈 어둠의 다크니스 | 1 | 1 | 1배 | 불지옥 + 튜토리얼을 뺀 모든 층 암흑(`allDark`) |

- 공통 속도: `PLAYER_SPEED = 4.08`(처음 3.4의 1.2배), 모든 균에 `GERM_SPEED = 1.15`를 곱한다.
- 처음 화면에서 난이도를 바꾸고 '이어 하기'를 누르면 새 난이도 적용. 모은 조각·위치·비누는 유지, 목숨·균 수·거미줄은 새 난이도에 맞춤(`Game.changeDiff`).

**암흑**: 과정의 마지막 층(1시간용 5층, 2시간용 6층)과 다크니스의 모든 층. 주인공 둘레만 밝고, 쫓는 균의 `!`, 열린 탈출문, 안내 화살표는 어둠 위에 그린다(`drawDark`).

**거미줄**(불지옥·다크니스): 층마다 바닥에 8개, 밟으면 사라지고 4.5초 동안 40% 감속(`WEB_TIME`, `WEB_SLOW`, `WEB_COUNT`).

**쪽지 4/4**: 쪽지 단추가 금색 바탕·"✨ 다 모았어요! 눌러요" 금색 띠·반짝임·흔들기(`#noteBtn.ready`).

**문제**: 저학년 2층에 "학교 급식에 나오는 김치가 아닌 것은?" 1문제 추가. 학교공급 김치 목록(한국농협김치 2026-2학기 19품목, 이름 같은 2개를 합쳐 18) 중 3개 + 정답 단무지/피클 중 하나. 게임을 열 때마다 새로 뽑는다. 영양교사 멘토 피드백으로 고친 문제들(딸기·수박은 채소, 식품군·비타민C 문항 등)도 반영돼 있다.

**선생님 기능**
- 첫 화면 오른쪽 아래 👩‍🏫 → 비밀번호 → 반별 진행 표(층별 별, ⏭ 건너뜀, 난이도, 마지막 접속).
- 게임 중 주인공을 빠르게 7번(간격 1.2초 이내) 누름 → 비밀번호(⌫ 지우기·✕ 닫기, PC 키보드 숫자·Backspace·Esc) → **선생님 메뉴**
  - 📍 순간이동: 출발 자리·이 층의 방으로(진행 유지, 잠깐 무적)
  - 🪜 층 옮기기: 학생 과정의 층(튜토리얼 포함). 앞으로 건너뛴 층은 별 0개 `skipped: true`

**버그 수정 기록(재발 시 참고)**
- 장애물에 끼임: 자동 저장 때 주인공 위치를 반올림해서 몸이 벽에 박혔다. 반올림 제거 + `Game.unstick()`(박혀 있으면 가장 가까운 빈 자리로)을 매 프레임·이어 하기 때 호출.
- 웹에서 예전 버전이 뜸: 예전 `sw.js`가 저장본을 먼저 보여 줬다. 지금은 네트워크 우선.
- 이어 하기에서 난이도 미적용: 위 '이어 하기' 항목 참고.

## 5. 검증 방법(다음 사람이 쓰기 좋은 것)
- 로컬 서버: `nyamnyam/.claude/launch.json`의 `python -m http.server 8765`.
- 브라우저 탭이 화면에 안 보이면 `requestAnimationFrame`이 초당 1번으로 느려져서 실제 플레이 확인이 어렵다. 대신 페이지 안에서 `await import('/js/game.js?v=' + Date.now())`로 `Game`을 직접 만들고 `update(0.05)`를 반복 호출하면 실제 코드로 이동·충돌·균·문·화살표를 잴 수 있다(가짜 `ui` 객체만 넘기면 됨).
- UI 흐름은 `localStorage`에 `nyam1:c15:n30` 같은 시험용 기록을 써 두고 시작 → 반 → 번호 → 이어 하기를 클릭해서 확인. 확인 뒤 그 키를 지운다.
- `style.css`는 브라우저가 캐시하므로 확인 전에 `?v=` 붙여 다시 불러온다.

이번까지 검증한 것: 지도 자동 검사 7층 통과, 실제 이동으로 모든 ?가구·숨는 곳·탈출문 접근, 복도 균 추격, 매우 쉬움 화살표만 따라가기 360판 전부 탈출, 거미줄 0.6배·4.5초, 7번 누르기·비밀번호·층 옮기기·순간이동, 끼임 재현 후 해결, 옛 저장 이어 하기.

## 6. 남은 일·미검증
- **터치(가상 조이스틱)로 직접 플레이**, 태블릿·교실 TV 실제 화면: 미검증. 키보드·코드 수준만 확인.
- **소리**(배경음악, 문 소리): 귀로 확인한 적 없음.
- **반 전체 기록 모으기**: 지금은 기기마다 따로라 아이들이 각자 폰으로 하면 선생님 PC에 안 보인다. Google Sheets(Apps Script 웹앱)로 모으는 안을 제안했으나 **사용자 답 대기 중**.
- **QR 코드**: 만들지 못했다(이 환경에서 `qrcode` 패키지 설치가 막힘). Chrome의 "이 페이지의 QR 코드 만들기"를 안내함.
- `maptest/` 검증용 사본은 지도 적용 직후 버전이라 이후 기능(난이도 6개, 문, 거미줄 등)이 없다. 지도를 다시 고칠 때 `js/`에서 다시 복사하거나 지워도 된다(공개 사이트에 같이 올라가 있음).
- 문제 은행 공유 페이지(claude.ai 아티팩트 `MizmXoJyqk1zx3YKrvLwdo`)에는 김치 문제와 이후 문항 수정이 없다.
- 사용자에게 확인하면 좋을 선택지(지금은 기본값으로 둠): 거미줄 효과를 층 끝까지 유지할지, 무말랭이를 김치 보기에서 뺄지, 다크니스 아이콘 😈/👿, 첫 화면 기본 난이도(지금 '중간').
