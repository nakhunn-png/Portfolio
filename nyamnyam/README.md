# 냠냠 탈출 대작전

초등 교실용 영양 교육 탈출 게임. 균을 피해 ?가구의 문제를 풀고, 쪽지 조각 4개를 모아 순서대로 붙인 뒤 영양 문제를 맞히면 탈출문이 열린다.

- 혼자 하기 전용, 서버 없음. 태블릿(터치)과 노트북(키보드) 모두 지원
- 한 번 열면 인터넷이 끊겨도 작동(오프라인), 몇 초마다 자동 저장 → 새로고침해도 하던 자리부터 이어 하기
- 기록은 각 태블릿 안(브라우저 저장소)에 반·번호별로 저장

## 흐름
타이틀(난이도 선택) → 반(1~15) → 번호(1~30) → 학년군(저·중·고) → 1시간용/2시간용 → 주인공 → 0층 연습(건너뛰기 가능) → 본 층

| 과정 | 층 |
|---|---|
| 1시간용 | 1층 급식실 · 2층 냉장고 채소칸 · 5층 시장 |
| 2시간용 | 1~6층 전부 (급식실, 채소칸, 우유·고기칸, 텃밭, 시장, 주방) |

## 규칙 한눈에
- ?가구 10개 중 4개에만 진짜 쪽지 조각. 가구 앞에서 문제를 맞혀야 뒤질 수 있고, 틀리면 6초 동안 잠김
- 감지기: 조각과 멀어요 → 조금 가까워요 → 가까워요! → 아주 가까워요! → 바로 여기예요! (누르면 영양이가 방 이름을 알려 줌)
- 숨는 곳(고학년은 "쉘터"): 들어가 있으면 균이 못 찾음
- 🫧 비눗방울: 가까운 균에게 날아가 4초 동안 멈춤. 바닥의 🧼 비누를 주워 채움
- 💧 물 한 컵: 5초 빨라짐 · 😷 마스크: 6초 동안 균이 알아채지 못함
- 쪽지 문제 오답: 쉬움·어려움은 힌트를 보여 주고 다시 풀기(고른 오답은 다시 못 고름), 불지옥은 조각이 다시 흩어짐
- 균 3종: 꼬물이(보통), 곰팡돌이(느리지만 멀리 봄), 충치쟁이(빠르지만 금방 지침)

| 난이도 | 목숨 | 균 |
|---|---|---|
| 🙂 쉬움 | 무한 | 느리고 적음 |
| 💪 어려움 | 3개 | 빠르고 많음 |
| 🔥 불지옥 | 1개 | 빠르고 많음 |

잡힐 때마다 난이도를 바꿀 수 있고, 바꾸면 그 층을 처음부터 다시 한다. 목숨을 다 쓰면 그 층 처음부터.

별점(층마다 3개): 탈출 / 문제를 2번 이하로 틀리기 / 바닥의 비누 60% 넘게 줍기

## 선생님
- 타이틀 오른쪽 아래 **👩‍🏫 선생님** → 비밀번호 `0303` → 반별 진행 표(층별 별, 난이도, 마지막 접속), 학생·반 기록 지우기
- 비밀번호는 `js/data.js`의 `TEACHER_PIN`. 코드가 공개돼 있으므로 학생의 실수를 막는 정도의 잠금이다
- **문제 고치기:** `js/questions.js`의 해당 줄을 바꾼다. 한 줄 = `[문제, 정답, 오답, 오답, 오답, 힌트]`
- **파일을 고친 뒤에는** 두 가지를 한다
  1. 묶기: 이 폴더에서 `npx esbuild@0.24.0 js/ui.js --bundle --format=iife --target=es2019 --outfile=js/app.js --legal-comments=none` → `js/app.js`가 새로 만들어진다(화면은 이 파일을 쓴다)
  2. `sw.js`의 `VERSION`을 올린다(예: `nyam-v3` → `nyam-v4`). 태블릿은 다음에 열 때 새 버전을 받는다

## 구조
```
index.html, style.css, sw.js(오프라인), manifest.webmanifest
js/data.js       층·테마·균·난이도·대사·비밀번호
js/questions.js  학년군 3개 × 6층 × 15문제 = 270문제
js/map.js        층 지도 만들기(씨앗이 같으면 같은 지도), 시야, 길찾기
js/game.js       한 층의 판정과 그리기, 연습 층 단계
js/ui.js         화면 흐름, HUD, 창, 저장 연결, 선생님 화면
js/save.js       반·번호별 저장
js/sound.js      합성 효과음(기본 꺼짐)
js/app.js        위 파일들을 하나로 묶은 것(직접 고치지 않음)
img/             캐릭터·균·영양이·타이틀 그림
```

로컬 실행: `index.html`을 더블클릭해도 된다(인터넷이 끊겨도 열리게 하는 오프라인 저장은 인터넷 주소로 열 때만 작동).
