# 보안코드 연습

예약·청약 사이트의 6자리 숫자 보안코드 입력을 미리 연습하는 단일 HTML 페이지입니다.

## 기능

- 3, 2, 1 카운트다운 뒤 랜덤 6자리 숫자 표시
- 입력 후 Enter를 눌러야 채점 → **Correct**(초록) / **Fail**(빨강)
- 코드가 표시된 순간부터 Enter까지 걸린 시간을 `1.0130s`처럼 소수점 넷째 자리까지 표시
- 정답 수/시도 수, 최고 기록, 정답 평균 시간, 회차별 기록 표

## 사용법

`보안코드 연습.html`을 브라우저로 열면 바로 시작됩니다. 채점 후 Enter를 한 번 더 누르면 다음 코드로 넘어갑니다.
