description: 세무 쟁점을 법령 원문(법제처)+예규+웹으로 교차검증하고, 전 세법 가산세 스윕까지 돌려 근거 조문이 달린 회신 초안(.md)을 작성. 근거 못 찾으면 "확인 불가".

세법자문-회신 스킬을 사용해서 아래 이슈에 대한 회신 초안을 작성하라.

이슈: $ARGUMENTS

`세법자문-회신` 스킬의 절차(0~5단계)를 그대로 따른다:
1. 쟁점 정규화 + 비식별 + **과세기간 명시**
2. 실체·절차 조사 — `scan_articles` 로 해당 세목법 **및 시행령**을 훑는다 (서식 의무는 시행령에 있다)
3. **누락 스윕 (해당하면 생략 불가)** — 먼저 판정한다. **미제출·지연·누락·기한 도과 같은
   "어긋난 사실"이 있거나 / 수정신고·경정청구·기한후신고가 쟁점이거나 /
   질문이 불이익을 물을 때만** 돈다. 순수 해석·사전 계획 질문이면
   건너뛰고, **건너뛴 사유를 검토 범위에 한 줄 남긴다.**
   돌린다면 `세법자문-회신` 스킬 폴더의 `references/가산세-스윕.md` 의
   A세트(국세기본법·조세특례제한법·국세징수법)
   + B세트(해당 세목법·시행령·시행규칙)를 축별 키워드로 `scan_articles`
4. **적용시점** — `get_addenda(keywords=["적용례","경과조치"])` 로 부칙 확인.
   **"언제부터 적용되나"는 조문이 아니라 부칙에 있다.** + `amendment_track` 개정 이력
   + WebSearch 로 국세청 예규·심판례 보강 (예규는 `search_decisions` 에 없다)
5. **산출물** — 내부검토용은 **항상**(가산세·부담액 표 + 검토 범위 표 + 근거등급).
   발송용은 **받는 사람이 있을 때만** — 고객 메일·질의서가 입력이거나 "회신·답변" 요청일 때.
   발송용은 위 셋을 빼되, 확인 못 한 것은 「확인이 필요한 사항」에 문장으로 옮긴다.
   애매하면 내부용만 만들고 "발송용이 필요하면 말씀해 주세요"를 붙인다.
6. `세법자문_{주제}_내부.md` (+ 해당 시 `세법자문_{주제}_회신.md`) 저장 + (선택) Gmail 초안(발송금지)·Notion 기록 + 자가점검

원칙:
- 모든 결론에 근거 조문(법령명·조문번호·**항**·시행일). 못 찾으면 "확인 불가", 지어내기 금지.
- `search_law` 는 법령명 전용이다. **내용으로 조문을 찾을 때는 `scan_articles`.**
- 쟁점이 어느 세목이든 **조세특례제한법을 반드시 스윕에 넣는다**(특별법 우선).
- 안 훑은 법령은 검토 범위 표에 **미확인**으로 남긴다. 침묵은 "해당 없음"이 아니다.
- **발송용은 내부용에서 덜어내는 것이지 더 단정하는 게 아니다.** 근거등급은 지우되
  확인 못 한 사항은 반드시 문장으로 남긴다.
- 가산세는 **매번 다루는 게 아니다.** 어긋난 사실이 없으면 안 돌리되, 안 돌렸다고 적는다.
- 가산세를 다뤘고 **법인세·소득세 가산세를 찾았으면 지방소득세 10%(지방세법 §103의30·§99)를 더한다.**
- 부칙 조회가 비어도 "부칙 없음"이 아니다. 원문 확인 후 못 찾으면 **"부칙 미확인"**.
- 초안을 저장하기 전 **인용 조문번호를 전수 재확인**한다(조사한 것과 적은 것이 다를 수 있다).
  인용 건마다 **서브에이전트**를 띄우고 **조문번호와 인용 취지 한 줄만** 준다 — 초안 전문은 주지 마라.
  자기 초안을 본 검증자는 "취지상 맞다"로 합리화한다.
- 저장 직전 **누락 비평 서브에이전트** 1개에게 초안·검토범위표만 주고 **"안 본 것이 무엇인가"**만 묻는다.
  **조건부다** — 3축을 돌렸거나 / 발송용을 만들거나 / 세목이 둘 이상일 때만. 순수 해석 질문이면
  건너뛰고 `누락 비평: 미실시 — 사유`를 검토 범위에 적는다(건너뛰어도 「보지 않은 것」은 직접 채운다).
  지적은 하나씩 판정하고, 반영 안 하면 사유를 검토 범위에 적는다. 지적이 없으면 `누락 비평: 지적 없음`.
- **결론에 날짜·기한을 적었으면 검토 기준일과 대조한다.** 이미 지난 기한을 "지금 하면 된다"고 쓰면 오작동한다.
- **출처 URL 은 도구가 준 것을 그대로 옮긴다.** 링크를 조립하면 지어낸 것이다.
- 국세청 예규는 법원(法源)이 아니라 과세관청 시각이다. 조문을 먼저 대고, 어긋나면 `[불일치]`.

이슈가 비어 있으면 어떤 세무 쟁점을 검토할지 한 문장으로 물어라.
