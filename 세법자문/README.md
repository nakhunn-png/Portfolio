# 세법자문 — Claude Code 스킬

세무 쟁점을 법령 원문·예규·웹으로 교차검증하고, 가산세 누락 여부까지 확인해
근거 조문이 달린 회신 초안을 만드는 Claude Code 스킬입니다.

## 구성

| 파일 | 역할 |
|---|---|
| `commands/세법자문.md` | `/세법자문 <이슈>` 로 실행하는 명령어 |
| `skills/세법자문-회신/SKILL.md` | 조사 → 누락 스윕 → 교차검증 → 회신 초안 작성 절차 |
| `skills/세법자문-회신/references/가산세-스윕.md` | 가산세 점검 참고자료 |

## 사용법

1. `commands/세법자문.md` 를 `~/.claude/commands/` 에 복사합니다.
2. `skills/세법자문-회신` 폴더를 `~/.claude/skills/` 에 복사합니다.
3. Claude Code에서 `/세법자문 <검토할 세무 이슈>` 를 입력합니다.

> 실무 참고용이며 공식 유권해석이 아닙니다.
