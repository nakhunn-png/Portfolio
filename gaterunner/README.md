# 덧뺄셈 복습 게이트러너

초등 1학년 덧셈·뺄셈 복습용 달리기 웹 게임. 서버 없이 정적 파일로 돌아간다. 자세한 기획은 [기획서.md](기획서.md).

## 하는 법
- 화면 위 문제를 풀고, 정답이 적힌 문으로 달려간다. 화면 왼쪽·가운데·오른쪽을 누르거나 옆으로 끌면 줄을 옮긴다.
- 숫자 문을 직접 누르면 그 줄로 가면서 빨리 달린다.
- 주인공은 엽전을 계속 쏜다. 문제 사이에는 능력 문(연사·관통·분열·방어막·이동), 균 무리, 엽전을 맞힐수록 숫자가 커지는 움직이는 친구 문, 친구 수 조건을 채우면 옷을 주는 옷 문이 지나간다.
- 모은 옷은 단계 고르기 화면 아래 옷장에서 입고 벗는다.
- 맞히면 친구 3명이 합류하고, 틀리면 2명이 떨어지면서 10칸 틀 힌트가 나온다. 게임 오버는 없다.
- 문제 10개를 풀고 나면 보스전(3문제)을 한다. 별 2개 이상이면 다음 단계가 열린다.

## 선생님
- 처음 화면 오른쪽 아래 '선생님' → 비밀번호 `0303` (`js/data.js`의 `TEACHER_PIN`).
- 반별 학생 기록(단계별 별, 유형별 정답률, 자주 틀린 문제, 실수 종류), 문 속도, 효과음, 모든 단계 열기, 기록 지우기.
- 기록은 **학생이 게임을 한 기기**의 브라우저에만 저장된다(`localStorage`, 키 `gate1:c{반}:n{번호}`).

## 고칠 때
| 무엇 | 어디 |
|---|---|
| 단계 구성, 문 속도, 보스 체력, 친구 늘고 주는 수, 옷 목록 | `js/data.js` |
| 달리는 속도, 능력 종류·최대치, 이벤트 확률 | `js/game.js` 맨 위 상수와 `POWERS`, `spawnEvent` |
| 문제 범위, 오답 보기 | `js/questions.js` → 고친 뒤 `node tests/check-questions.js` |
| 달리기·보스 그리기와 판정 | `js/game.js` |
| 화면, 힌트, 저장 연결, 선생님 화면 | `js/ui.js`, `index.html`, `style.css` |

- 묶기 단계가 없다. 파일을 고치면 바로 반영된다.
- 배포 전에 `sw.js`의 `VERSION`을 하나 올린다(`gate-v1` → `gate-v2`). 이미 연 기기는 다음에 열 때 새 버전을 받는다.
- 내 컴퓨터에서 보기: `gaterunner` 폴더에서 `python -m http.server 8766` → http://localhost:8766
- 검사용 함수: 개발자 도구에서 `GRGame._step(초)`로 시간을 흘려 보내고 `GRGame._state()`로 상태를 볼 수 있다.
