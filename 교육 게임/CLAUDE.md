# 냠냠 랜덤 디펜스 2 — Claude 작업 안내

초1 2학기 덧셈·뺄셈(2·4·6단원) 뺑뺑이 디펜스. 1편 `nyam-defense/` 의 후속작이며 1편 파일은 고치지 않는다.

**작업을 시작하면 먼저 읽을 것**
1. [HANDOFF.md](HANDOFF.md) — 지금 상태, 실행법, 파일 구성, 검사, 밸런스 기준, 다음 할 일
2. [PRD.md](PRD.md) — 기획과 모든 결정. 진행 기록은 16장. 이후 결정은 PRD 를 기준으로 본다

## 사용자와 일하는 법 (꼭 지킨다)

- 새 게임·기능 기획은 **글로 길게 쓰지 말고 그림(위젯)부터** 보여 주고, 확인받은 뒤 PRD 를 쓴다.
- 스테이지가 많으면 지루해한다. 판마다 분위기·구성을 확 바꿔 새로움을 준다.
- 화면 글은 모두 쉬운 한국어(1학년용). 버튼은 최소 56px.
- 진행 상황과 바꾼 수치는 PRD 16장에 적는다.
- 사용자가 미리보기 창에서 직접 플레이하는 중일 수 있다. 시험은 `127.0.0.1:8767` 별도 탭에서 한다(localhost 와 저장이 따로라 섞이지 않는다).

## 밸런스 원칙 (사용자 피드백으로 정해진 것)

- **적은 적고 단단하게.** 나오자마자 죽으면 디펜스가 아니다. 첫 웨이브 적이 길을 15% 넘게 가야 한다(`tests/check-speed.js`).
- **난이도는 한 단계마다 확실히 어려워진다**(`tests/check-difficulty.js`). 튜토리얼 → 쉬움 → 보통 → 어려움 → 아주 어려움 → 재앙.
- 「쉬움」은 정답률 75%로도 거의 이긴다(뒤처진 학생용). 「보통」부터 생명을 잃는 긴장감.
- **아크메이지는 약하게 만들지 않는다.** 선생님이 뒤처진 학생에게 몰래 골라 주는 도움 영웅이라 일부러 아주 강하다. 밸런스 시험에서도 뺀다.
- 수치는 `js/config.js` 에서만 바꾼다. 바꾼 뒤에는 검사 6개를 돌린다(HANDOFF.md 「검사」).

## 실행·검사

- 실행: 이 폴더에서 `python -m http.server 8767` → `http://localhost:8767` (`?dev=1` 은 모두 열기)
- 미리보기: `.claude/launch.json` 의 `nyam-defense2`
- 브라우저 확인 때 창이 숨겨져 있으면 느리다. `G.UI._test.tick(초)` 로 시간을 흘려 보낸다.
