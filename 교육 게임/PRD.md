## 4. 한 판 흐름

```
스테이지 고르기 → 준비 시간(문제 → 코인 → 뽑기 → 배치) → 웨이브 자동 전투
  → 웨이브 사이 문제 → … → 결과(별 1~3개)
보스 스테이지: 준비 시간 → 부하 웨이브 2개 → 보스전(수동) → 결과
```

- 준비 시간에는 문제 5개. 웨이브 사이에는 문제 3개.
- 전투 중에도 문제 풍선이 실제 시간 20초마다 하나씩 떠오른다. 누르면 전투가 잠깐 멈추고 문제가 나온다. 안 눌러도 10초 뒤 사라진다(벌점 없음).
- 문제를 푸는 동안에는 언제나 전투가 멈춘다. 배속과 상관없이 아이가 생각할 시간은 줄지 않는다.

## 8. 보스전 (수동 조작)

보스 스테이지는 **부하 웨이브 2개 → 문제 3개 → 보스**로 흘러간다. 보스가 나오면 친구들은 계속 자동으로 싸우고, 아이는 고른 **영웅**(18장)을 대장으로 직접 움직인다. 화면을 누르거나 끌면 영웅이 그쪽으로 걸어간다.

| 화면 | 하는 일 |
|---|---|
| 위 가운데 체력 막대 | 보스 이름과 남은 체력 (마왕은 몇 단계인지, 문어는 기절했는지) |
| 왼쪽 아래 **보스 문제 칸** | 전투를 멈추지 않고 문제가 계속 나온다. 맞힐 때마다 코인과 **필살기 칸 1개** |
| 가운데 아래 필살기 버튼 | 필살기 칸 3개가 차면 영웅 능력을 쓴다. 보스전 동안은 능력 대기 시간 대신 이 칸으로만 찬다 |
| 오른쪽 아래 문어 다리 (문어 대장만) | 다리 숫자 두 개를 차례로 누른다. 더해서 10이면 싹둑 |

| 보스 | 길 | 패턴 | 아이가 할 일 |
|---|---|---|---|
| 문어 대장 | 소용돌이 바다의 큰 타원 | 다리 8개가 남아 있으면 받는 피해가 30%로 준다. 다리를 다 자르면 5초 기절, 그동안 피해 2배. 22초 뒤 다리가 다시 자란다 | 더해서 10이 되는 다리 두 개 고르기 (1+9, 2+8 …) |
| 전갈 왕 | 뾰족한 네모 경기장 | 5초마다 독침 3개: 영웅 자리, 친구 자리, 보스 근처에 빨간 원이 1.5초 먼저 뜬다. 맞으면 영웅 3초 기절, 친구 2초 얼음 | 영웅을 끌어 빨간 원 밖으로. 보스 문제는 7초 안에 맞히기(시간 막대) |

- 보스가 길을 한 바퀴 다 돌면 생명 2를 잃고 다시 돈다.
- 보스전은 **최대 1.5배속**이다(9장). 보스 체력은 `boss.hp × 스테이지 hp × 난이도 bossHp`.
- 보스에게 지면 결과 화면에 「보스 다시 도전 (체력 절반부터)」 버튼이 나온다. 문제 3개를 맞히면 생명을 다 채우고, 보스 체력은 절반(이미 절반보다 적었으면 그대로)부터 다시 싸운다.
- 과자 숲을 깨면 2배속(2026-11-26, 전에는 문어 대장), 전갈 왕을 깨면 2.5배속이 열린다.
- 검사: `node tests/check-boss.js` (영웅 4명 × 4판, 아크메이지는 일부러 강한 도움 영웅이라 기준에서 뺀다). 2026-11-25 결과: 「보통」 승률 94~100%, 보스전 실제 시간 1분 40초~2분 35초.

## 9. 배속과 클리어 시간 보정

### 9-1. 배속 종류

| 배속 | 열리는 때 |
|---|---|
| 1배속 | 처음부터 |
| 1.5배속 | 처음부터 |
| 2배속 | 스테이지 1(과자 숲)을 깨면 (2026-11-26) |
| 2.5배속 | 스테이지 6(전갈 왕)을 깨면 |

- 전투 화면 오른쪽 위 버튼으로 바꾼다. 누를 때마다 다음 배속으로 넘어간다. 멈춤 메뉴에서도 고를 수 있다(1편과 같음).
- 선생님은 반 전체의 최대 배속을 정할 수 있다(12장).

### 9-2. 문제점

배속은 게임 시계를 빠르게 돌린다. 적과 아군이 똑같이 빨라지므로 난이도는 거의 같고, **전투 시간만 짧아진다**. 1배속 4분짜리 전투가 2.5배속이면 1분 36초에 끝난다. 그러면

1. 한 판이 너무 빨리 끝나 허전하다.
2. 전투 시간에 묶인 문제(전투 중 문제 풍선)가 줄어 수학 연습량이 줄어든다.
3. 빠른 아이가 클리어 시간 기록을 쉽게 가져간다.

### 9-3. 보정 원칙

**원칙 1. 문제는 실제 시간에 묶는다.**
전투 중 문제 풍선은 게임 시계가 아니라 실제 시간 20초마다 뜬다. 문제를 푸는 동안에는 언제나 멈춘다. 배속을 올려도 1분에 만나는 문제 수는 같다.

**원칙 2. 배속이 오를수록 웨이브와 적을 늘린다.**
게임 안 분량을 늘려 실제 전투 시간을 3분 40초 안팎으로 맞춘다.

| 배속 | 웨이브 | 적 수 배율 | 실제 전투 시간 | 한 판 문제 수 |
|---|---|---|---|---|
| 1배속 | 4 | 1.0 | 약 4분 00초 | 약 20 |
| 1.5배속 | 5 | 1.1 | 약 3분 40초 | 약 22 |
| 2배속 | 6 | 1.2 | 약 3분 36초 | 약 25 |
| 2.5배속 | 7 | 1.3 | 약 3분 38초 | 약 28 |

- 실제 전투 시간 = 웨이브 수 × 웨이브 길이(게임 시간 60초) × 적 수 배율 ÷ 배속. 문제 푸는 시간(문제당 약 6초)은 따로 더해진다.
- 한 판 문제 수 = 준비 5 + 웨이브 사이 3 × (웨이브 − 1) + 문제 풍선(아이가 절반쯤 누른다고 보고 약 5~6개).
- 웨이브 사이 문제(웨이브마다 3개)가 늘어나므로, 빠르게 하는 아이가 오히려 문제를 더 많이 푼다.
- 늘어난 웨이브에는 「터보 적」(번쩍이는 테두리, 코인 +5)을 섞어 빠른 판만의 재미를 준다.
- 보스 스테이지는 부하 웨이브만 이 표를 따르고(2 → 최대 3), 보스전은 1.5배속으로 고정한다.

**원칙 3. 최소 문제 수를 지킨다.**
스테이지를 깨려면 최소 15문제를 맞혀야 한다. 마지막 웨이브가 끝났는데 15개가 안 되면 「마무리 문제」를 모자란 만큼 낸다. 어떤 배속에서도 한 판의 수학 연습량이 이 아래로 떨어지지 않는다.

**원칙 4. 기록은 배속별로 따로 잰다.**
- 별(11장)은 시간과 상관없다. 배속 때문에 별을 더 쉽게 받지 않는다.
- 스테이지 최고 기록은 배속별로 따로 보여 준다. 기록에는 실제 시간이 아니라 **정답 수와 남은 생명**을 쓴다.
- ~~2.5배속 전용 보상~~ → 보스전은 1.5배속이 상한이라 「보스 셋을 모두 1.5배속으로 깨면 번개 냠냠」으로 바꿨다(2026-11-26, 10-1).

### 9-4. 설정값 (`js/config.js`)

```js
speeds: [
  { name: '1배속',   v: 1,   count: 1.0, unlock: null },
  { name: '1.5배속', v: 1.5, count: 1.1, unlock: null },
  { name: '2배속',   v: 2,   count: 1.2, unlock: 3 },   // 스테이지 3을 깨면
  { name: '2.5배속', v: 2.5, count: 1.3, unlock: 6 }    // 스테이지 6을 깨면
],
battleTime: { targetRealSec: 220, waveGameSec: 66, minWaves: 4, maxWaves: 7 },
bossSpeedCap: 1.5,          // 보스전 최대 배속
questionBubbleSec: 20,      // 전투 중 문제 풍선 간격 (실제 시간)
minCorrectToClear: 15,      // 스테이지를 깨는 데 필요한 최소 정답 수
turboEnemyBonus: 5          // 터보 적 코인
```

### 9-5. 만들면서 정한 방식

- **웨이브 수는 표로 고정하지 않는다.** 웨이브가 끝날 때마다 「계획 실제 시간」(웨이브마다 적이 나오는 시간 ÷ 그때 배속)을 더해 보고, 목표 220초에 닿으면 끝낸다. 배속을 바꾸지 않으면 9-3 표대로 4·5·6·7개가 나오고, 중간에 배속을 바꿔도 알맞게 맞춰진다. 적을 다 잡는 마지막 몇 초는 판마다 달라서 계산에 넣지 않는다.
- **적이 많아진 만큼 웨이브도 길어진다.** 적이 나오는 간격은 배속과 상관없이 같다.
- **적의 세기는 웨이브 번호가 아니라 진행 정도로 정한다.** 진행 정도 = 그 웨이브 전까지의 계획 시간 ÷ 220초. 그래서 2.5배속 7번째 웨이브와 1배속 4번째 웨이브의 적 세기가 같다.
- 검사: `node tests/check-speed.js` 가 스테이지·배속마다 10판을 모의로 돌려, 이긴 판의 웨이브 수가 표와 같은지, 실제 전투 시간이 3분 20초~5분인지, 너무 쉽지 않은지 본다. 2026-11-25 결과는 1배속 3분 59초, 1.5배속 3분 36초, 2배속 3분 34초, 2.5배속 3분 34초.
