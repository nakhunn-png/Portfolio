# 냠냠 랜덤 디펜스 2 — 인수인계 (2026-11-26)

초등 1학년 2학기 덧셈·뺄셈(2·4·6단원) 뺑뺑이 디펜스. 기획과 결정 기록은 [PRD.md](PRD.md), 진행 기록은 PRD 16장.

## 지금 상태

- **main 에 커밋·push 한다.** 사용자는 여러 PC 에서 번갈아 이어 하므로 브랜치를 만들지 않는다(사용자가 브랜치를 쓰지 않는다). 다른 PC 에서는 Portfolio 폴더에서 `git pull` 만 하면 된다.
- Claude 작업 규칙은 [CLAUDE.md](CLAUDE.md) (이 폴더에서 작업하면 저절로 읽힌다).
- PRD 15장 만드는 순서 중 **1~6번 끝**: 뼈대, 배속 보정, 일반 스테이지 6개, 보스 3종, 도감·합성·도감 보상, 도전 영역(과제·탑·놀이 3개).
- 그 뒤에 사용자 피드백으로 밸런스를 세 번 고쳤다(아래 「밸런스」).
- **남은 일**: 15장 7번(선생님 기능·기록·오프라인), 8번(수업 시험). 튜토리얼은 아이와 직접 해 보지 않았다.

## 실행

```
python -m http.server 8767
```
- `http://localhost:8767` — 보통 플레이
- `http://localhost:8767/?dev=1` — 시험용: 모든 스테이지·배속·숨은 영웅·재앙 난이도·도전 영역이 열림
- 미리보기 설정: `.claude/launch.json` 의 `nyam-defense2`
- 저장은 브라우저 localStorage(`냠냠2_도감`, `냠냠2_진행`, `냠냠2_설정`). **localhost 와 127.0.0.1 은 저장이 따로**라서, 사용자가 쓰는 저장을 건드리지 않으려면 시험은 `127.0.0.1:8767` 에서 한다.
- localhost 쪽 저장에는 Claude 시험 흔적이 조금 있다(탑 9층 기록, 「척척 연속 정답」 → 무지개 요리사, 선물 코인).

## 파일

| 파일 | 하는 일 |
|---|---|
| `js/config.js` | **모든 수치** (난이도, 적, 스테이지, 영웅, 보스, 탑, 보상) |
| `js/battle.js` | 전투 계산(화면 없음, node 로 모의 가능). 길 모양 9개, 9번째 칸 자리(`extra`), 탑 층 |
| `js/collection.js` | 코인·뽑기·합성·출전 칸 |
| `js/mathgen.js` | 문제 유형 A1~C2 |
| `js/challenge.js` | 도감 보상, 도전 과제, 탑 테마·문제 단원, 놀이 3개 문제 만들기 (순수 계산) |
| `js/ui.js` | 화면 흐름 전부, 튜토리얼 안내 창(`guide()`), 능력 시간 막대(`skillLeft()`) |
| `js/plays.js` | 도전 영역 화면과 놀이 3개 화면 |
| `js/render.js`, `js/art/*` | 캔버스 그리기, 도트 그림 |

화면 흐름: 시작 → 스테이지 → **① 난이도** → **② 영웅** → 준비(문제·뽑기) → 웨이브 ↔ 문제 → (보스) → 마무리 → 결과. 도전 영역: 시작 화면 버튼(스테이지 3을 깨면 열림).

## 검사 (6개. 2026-11-26: check-speed 의 우주 정거장 1배속 시간이 가끔 실패, PRD 16장 맨 끝)

```
node tests/check-math.js        # 문제 범위
node tests/check-layout.js      # 칸·영웅·풍선이 길에 안 겹치는지 (9번째 칸 포함)
node tests/check-speed.js       # 일반 스테이지 × 배속: 웨이브 수, 전투 시간, 너무 쉬운지  (~4분)
node tests/check-boss.js        # 보스 스테이지                                         (~4분)
node tests/check-challenge.js   # 놀이 문제, 보상, 탑 층 수                             (~4분)
node tests/check-difficulty.js  # 난이도 사다리: 한 단계마다 확실히 어려워지는지        (~6분)
```
오래 걸리는 것은 백그라운드로 돌린다. 모의는 무작위라 경계 근처 값은 가끔 흔들린다.

## 밸런스 — 꼭 지킬 것

사용자 피드백 순서: 「너무 쉬워」(11-25) → 「나오자마자 5초도 안 돼서 죽는다, 디펜스 의미가 없다」(11-26) → 「난이도마다 한 단계씩 확실히 차이 나게」(11-26).

- **적은 적고 단단하게.** 첫 웨이브 적이 길을 평균 15% 넘게 가야 한다(`check-speed` 가 검사). 지금 보통 20~39%.
- **난이도 사다리**(문제 다 맞힘, 모의):

  | 난이도 | 일반 승률 | 보스 승률 |
  |---|---|---|
  | 튜토리얼 | 100% | 100% |
  | 쉬움 | 95% | 97% |
  | 보통 | 83% | 93% |
  | 어려움 | 62% | 83% |
  | 아주 어려움 | 43% | 53% |
  | 재앙 | 13% | 10% |

- 「쉬움」은 정답률 75%로도 거의 이겨야 한다(뒤처진 학생용).
- **아크메이지는 약하게 만들지 않는다**(선생님이 뒤처진 학생에게 몰래 골라 주는 도움 영웅). 밸런스 시험에서도 뺀다.
- 히든 친구는 판에 함께 오지 않는다(너무 세서 뺌). 선물 코인은 한 판에 60까지만.
- 도전의 탑 30층(마왕의 아이)은 잘하는 아이도 도전해야 닿는 목표: 보통 평균 20~28층.

- 번개 냠냠: 보스 2.5배속 → **1.5배속**(보스전 상한이 1.5배속)

## 사용자와 일하는 법
