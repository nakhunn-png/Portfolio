# 냠냠 랜덤 디펜스 2 — 인수인계 (2026-11-26 밤)

초등 1학년 2학기 덧셈·뺄셈(2·4·6단원) 뺑뺑이 디펜스. 기획과 결정 기록은 [PRD.md](PRD.md), 진행 기록은 PRD 16장(맨 끝이 가장 최근). **이 문서는 작업할 때마다 고쳐 쓴다**(사용자 요청).

## 지금 상태

- **main 에 커밋·push 한다.** 사용자는 여러 PC 에서 번갈아 이어 하고 브랜치를 쓰지 않는다. 다른 PC 에서는 Portfolio 폴더에서 `git pull`(GitHub Desktop: Fetch → Pull).
- Claude 작업 규칙은 [CLAUDE.md](CLAUDE.md).
- PRD 15장 만드는 순서 중 **1~6번 끝**(뼈대, 배속, 일반 6·보스 3, 도감, 도전 영역). 그 뒤 사용자 요청으로 고친 것(오늘):
  - 재앙 전용 어두운 맵(`js/art/stage.js` 의 `disaster()`, 불씨는 `render.js`)
  - **섬 지도**: 덧뺄셈 (1)·(2)·(3) 섬 그림만(세부 단계는 안 보임). 섬을 누르면 그 섬 스테이지를 차례로(일반 → 일반 → 보스), 결과 화면 「다음: ○○ ▶」
  - **난이도 화면**: 위 튜토리얼 한 줄 / 가운데 쉬움~아주 어려움 **2×2** / 아래 재앙(덧뺄셈 (3)을 아주 어려움 이상으로 깨면 열림, 전에는 「🔒 ? ? ?」)
  - 몹이 더 자주(적 수 ×1.4, 한 마리 체력 ×0.76), 모두 뽑기는 출전 칸을 넘지 않음, 2배속은 과자 숲을 깨면 열림, 합성 애니메이션(`mergeAnim`)
  - **튜토리얼** = 1-1 과자 숲 한 판(약 2분, 정답이 반짝임). 깨면 「본 게임 시작!」. 별·기록에 안 들어감
  - **식 세우기·문장제**(`mathgen.makeWord`): 교과서 상황. 식 세우기는 쉬움부터, 문장제는 어려움부터
  - 아크메이지: 빈 곳 **연속** 5번(1.2초 안), 메테오 대기 10초·피해 2500(치트키라 일부러 사기)
  - 모든 난이도: 능력 지속 15·18·12초, 보너스 풍선 2초, 능력 조준 중에도 전투가 흐름, 「모두 뽑기」→「전투 시작」 버튼이 반짝이며 유도
- **게임 전체 시간 어림 60~75분**(PRD 16장 끝). 사용자 기준 40~80분.

## 실행

```
python -m http.server 8767
```
- `http://localhost:8767` — 보통 플레이 / `?dev=1` — 모든 섬·배속·숨은 영웅·재앙·도전 영역 열림
- 바로 해 볼 링크(시험판, 모든 것 열림): https://claude.ai/artifact/XeuQbw2hPCjDBZLQB79cVJ — 코드를 바꾸면 Claude 가 같은 주소로 다시 올린다(`index.html` 에서 doctype·head 를 뺀 사본 + `DEV = true`)
- 저장은 localStorage(`냠냠2_도감`, `냠냠2_진행`, `냠냠2_설정`). localhost 와 127.0.0.1 은 저장이 따로 → 시험은 `127.0.0.1:8767`
- 파일을 바꾸면 `index.html` 의 `?v=` 번호를 올린다(브라우저 캐시). 지금 `2026112607`

## 파일

| 파일 | 하는 일 |
|---|---|
| `js/config.js` | **모든 수치**: 난이도(`word` 문제 비율 포함), 적, 스테이지, 영웅, 보스, 탑, 보상, `tutorialQuick` |
| `js/battle.js` | 전투 계산(화면 없음, node 모의). 튜토리얼 웨이브 길이 `waveMul` |
| `js/collection.js` | 코인·뽑기·합성·출전 칸. 모두 뽑기는 칸이 차면 멈춤(`full`) |
| `js/mathgen.js` | 계산 문제 A1~C2 + **식 세우기·문장제**(`SITU`, `makeWord`) |
| `js/challenge.js` | 도감 보상, 도전 과제, 탑, 놀이 3개 문제 |
| `js/ui.js` | 화면 흐름 전부: 섬 지도(`goMap`), 난이도(`renderDiffs`), 영웅, 문제(`renderQuiz`, `wordPicture`), 튜토리얼 안내(`guide`), 결과 |
| `js/plays.js` | 도전 영역과 놀이 3개 |
| `js/render.js`, `js/art/*` | 캔버스 그리기, 도트 그림, 재앙 맵 |

화면 흐름: 시작 → 섬 지도 → ① 난이도 → ② 영웅 → 준비(문제·뽑기) → 웨이브 ↔ 문제 → (보스) → 마무리 → 결과 → 「다음 스테이지」 또는 섬 지도.

## 검사 (6개)

```
node tests/check-math.js        # 문제 범위 + 식 세우기·문장제
node tests/check-layout.js      # 칸·영웅·풍선이 길에 안 겹치는지
node tests/check-speed.js       # 일반 스테이지 × 배속 (~4분)
node tests/check-boss.js        # 보스 스테이지 (~4분)
node tests/check-challenge.js   # 놀이·보상·탑 (~4분)
node tests/check-difficulty.js  # 난이도 사다리 (~6분)
```
오래 걸리는 것은 백그라운드로, 경계 값은 무작위로 흔들리니 **두 번** 돌려 본다. 마지막 결과(2026-11-26 밤): math·layout·challenge 통과, boss·difficulty·speed 는 2번 중 1번씩 경계에서 실패(위 「결정을 기다리는 것」).

화면 확인은 Playwright 로 `file://…/index.html?dev=1` 을 열고 `G.UI._test.startStage(no, 'mage', 난이도)`, `goPrep('prep')`, `tick(초)` 로 흘려 찍는다. 섬이 둥실거려서 클릭은 `{ force: true }`.

## 밸런스 — 꼭 지킬 것

사용자 피드백 순서: 「너무 쉬워」 → 「나오자마자 죽는다」 → 「난이도마다 확실히 차이」 → 「능력이 너무 빨리 끝나」(→ 능력 지속 늘림).

- **적은 적고 단단하게.** 첫 웨이브 적이 길을 평균 15% 넘게 가야 한다.
- **난이도는 한 단계마다 확실히 어려워진다.** 「쉬움」은 정답률 75%로도 거의 이긴다(뒤처진 학생용).
- **아크메이지는 약하게 만들지 않는다**(선생님이 뒤처진 학생에게 몰래 골라 주는 치트키). 밸런스 시험에서 뺀다.
- 히든 친구는 판에 안 옴. 선물 코인은 한 판 60까지. 탑 30층은 잘하는 아이의 목표.
- 수치는 `js/config.js` 에서만 바꾸고 검사 6개를 돌린다. 줄 번호로 `sed` 하지 말 것(줄이 밀려 적용 안 된 적이 있다).

## 사용자와 일하는 법

- 새 기능은 **글보다 그림(시안)부터** 보여 주고 확인받은 뒤 만든다.

- 끝나면 PRD 16장 기록 + **이 HANDOFF 고쳐 쓰기** + main push.
