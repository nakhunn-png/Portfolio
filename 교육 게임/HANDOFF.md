## 파일

| 파일 | 하는 일 |
|---|---|
| `js/config.js` | **모든 수치**: 난이도(`word` 문제 비율 포함), 적, 스테이지, 영웅, 보스, 탑, 보상, `tutorialQuick` |
| `js/battle.js` | 전투 계산(화면 없음, node 모의). 튜토리얼 웨이브 길이 `waveMul` |
| `js/collection.js` | 코인·뽑기·합성·출전 칸. 모두 뽑기는 칸이 차면 멈춤(`full`) |
| `js/mathgen.js` | 계산 문제 A1~C2 + **식 세우기·문장제**(`SITU`, `makeWord`) |
| `js/challenge.js` | 도감 보상, 도전 과제, 탑, 놀이 3개 문제 |
| `js/ui.js` | 화면 흐름 전부: 섬 지도(`goMap`), 난이도(`renderDiffs`), 영웅, 문제(`renderQuiz`, `wordPicture`), 튜토리얼 안내(`guide`), 결과 |
| `js/plays.js` | 도전 영역과 놀이 3개 |
| `js/render.js`, `js/art/*` | 캔버스 그리기, 도트 그림, 재앙 맵 |
| `js/audio.js` | 배경 음악(Web Audio 칩튠 3곡) |

화면 흐름: 시작 → 섬 지도 → ① 난이도 → ② 영웅 → 준비(문제·뽑기) → 웨이브 ↔ 문제 → (보스) → 마무리 → 결과 → 「다음 스테이지」 또는 섬 지도.

화면 확인은 Playwright 로 `file://…/index.html?dev=1` 을 열고 `G.UI._test.startStage(no, 'mage', 난이도)`, `goPrep('prep')`, `tick(초)` 로 흘려 찍는다. 섬이 둥실거려서 클릭은 `{ force: true }`.

## 밸런스 — 꼭 지킬 것

사용자 피드백 순서: 「너무 쉬워」 → 「나오자마자 죽는다」 → 「난이도마다 확실히 차이」 → 「능력이 너무 빨리 끝나」(→ 능력 지속 늘림).

- **적은 적고 단단하게.** 첫 웨이브 적이 길을 평균 15% 넘게 가야 한다.
- **난이도는 한 단계마다 확실히 어려워진다.** 「쉬움」은 정답률 75%로도 거의 이긴다(뒤처진 학생용).
- **아크메이지는 약하게 만들지 않는다**(선생님이 뒤처진 학생에게 몰래 골라 주는 치트키). 밸런스 시험에서 뺀다.
- 히든 친구는 판에 안 옴. 선물 코인은 한 판 60까지. 탑 30층은 잘하는 아이의 목표.
- 수치는 `js/config.js` 에서만 바꾸고 검사 6개를 돌린다. 줄 번호로 `sed` 하지 말 것(줄이 밀려 적용 안 된 적이 있다).
