# 자금일보 분류규칙 — (주)새봄푸드 (가상 회사, 연습용)

식품 원재료를 사서 마트·급식업체에 파는 가상의 유통 회사다. 계좌 3개.
위에서부터 보고 처음 맞은 줄 하나만 적용한다. `찾는 말`이 적요나 거래처에 들어 있으면 맞은 것이다.

## 규칙

| 순서 | 구분 | 찾는 말 | 자금코드 | 비고 |
|--:|---|---|---|---|
| 1 | 양쪽 | 내부이체 | 계좌 간 이체 | 입금·출금 합계에서 뺀다 |
| 2 | 입금 | 대출 실행 | 차입금 | |
| 3 | 입금 | 매출대금 | 매출대금 회수 | |
| 4 | 입금 | 카드매출 | 카드매출 정산 | |
| 5 | 출금 | 매입대금 | 원재료 매입 | |
| 6 | 출금 | 급여 | 급여 | |
| 7 | 출금 | 원천세 · 지방소득세 · 국민연금 · 건강보험 · 부가가치세 | 세금·4대보험 | |
| 8 | 출금 | 카드 결제대금 · 카드결제 · 결제대금 | 카드대금 | |
| 9 | 출금 | 임차료 | 임차료 | |
