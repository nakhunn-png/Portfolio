# 자금일보 연습 자료 — (주)새봄푸드 (가상 회사)

신입 연습용 **가상** 거래내역이다. 실제 회사·계좌·인물과 관계없다.

| 파일 | 내용 |
|---|---|
| `data/bank_accounts.csv` | 계좌 3개(주거래·급여·세금·운전자금), 9/30 기초 잔액, 10/30 기말 잔액 |
| `data/bank_transactions.csv` | 2026-10-01 ~ 10-30 거래 153건 (21영업일, 10/9 한글날 휴일) |
| `data/cash_schedule.csv` | 11/2 ~ 11/13 입출금 예정 8건 |
| `분류규칙_새봄푸드.md` | 자금코드 규칙 11줄 + 예측 표 |
| `자금일보_대시보드_새봄푸드.html` | 자금일보 스킬로 만든 결과 대시보드 |
| `자금일보_2026-10-30.md` | 10/30 기준 자금일보 |
| `자금일보_쉬운해설서.html` · `.pdf` | 신입용 쉬운 해설서 (용어·공식·화면 읽는 법·함정·퀴즈) |

## 다시 만들기

```bash
python .claude/skills/자금일보/scripts/build.py --입력 자금일보_연습/data --규칙 자금일보_연습/분류규칙_새봄푸드.md --출력 자금일보_연습/자금일보_대시보드_새봄푸드.html --회사 "(주)새봄푸드 (가상)" --큰출금 30000000
```
