## 1. 개요

| 항목 | 내용 |

| 이름 | 열매 마을 축제 |
| 대상 | 초등학교 1학년 2학기 |
| 교과 | 수학 2단원 덧셈과 뺄셈(1), 4단원 덧셈과 뺄셈(2), 6단원 덧셈과 뺄셈(3) |

| 기록 | 교사용 진도·정답률 화면 **없음**. 학생 진행만 태블릿에 저장 |
| 학급 특성 | 학생 간 수준 차이가 매우 큼 |

### 1.1 목표
1. 세 단원의 핵심 계산 전략을 놀이로 다시 익힌다. 핵심은 **10 만들기 → 10을 거쳐 계산하기 → 10묶음과 낱개로 계산하기**.
2. 수준이 낮은 학생도 **80분 안에 엔딩을 본다**.
3. 수준이 높은 학생은 높은 단계와 히든 요소로 남는 시간을 채운다.
4. 틀려도 위축되지 않게 한다. 벌점, 생명, 시간 제한을 두지 않는다.

### 1.2 하지 않는 것
- 교사용 대시보드, 서버 저장, 순위표
- 학생 이름 입력 (반·번호만 쓴다)
- 받아올림이 있는 두 자리 수 계산 (1학년 범위 밖)

## 2. 세계관과 이야기

**열매 마을에서 축제가 열린다.** 주인공 '톡이'가 마을 친구들을 도와 축제를 준비한다.

| 장면 | 내용 |
|---|---|
| 프롤로그 | 촌장 부엉이: "축제가 사흘 남았어요! 열매를 따고, 물건을 나르고, 달걀빵을 구워야 해요." |
| 스테이지 1 열매 과수원 | 다람쥐 '토리'와 축제에 쓸 열매를 딴다 |
| 스테이지 2 택배 마을 | 고슴도치 '고미'와 축제 물건을 트럭으로 나른다 |
| 스테이지 3 달걀 가게 | 닭 '꼬꼬'와 달걀빵 주문을 처리한다 |
| 엔딩 | 축제가 열리고 동료 셋이 모인다. 10 조각 3개를 모았으면 히든 친구 '열이'가 나타난다 |

- **톡이**: 동그란 씨앗 모양 캐릭터. 성별이 드러나지 않게 한다.
- **열이**: 10개의 빛 점이 둘러싼 별 요정. 숨겨진 친구.

## 3. 전체 흐름과 시간 설계

```
[반·번호 고르기] → [프롤로그] → [마을 지도]
   → 스테이지 1 (정거장 ①②③ → 대장 문제) → [쉼터]
   → 스테이지 2 (정거장 ①②③ → 대장 문제) → [쉬는 시간 화면]
   → 스테이지 3 (정거장 ①②③ → 대장 문제) → [엔딩]
   → [히든 단계 · 쉼터 · 다시 도전] (남는 시간)
```

| 교시 | 시간 | 내용 |
|---|---|---|
| 1교시 | 0~3분 | 반·번호, 프롤로그 |
| | 3~21분 | 스테이지 1 |
| | 21~39분 | 스테이지 2 |
| | 39~40분 | 쉬는 시간 화면 (자동 저장) |
| 2교시 | 0~18분 | 스테이지 3 |
| | 18~20분 | 엔딩 |
| | 20~40분 | 히든 단계, 꾸미기, 다시 도전 |

- **기본 완주 약 58분.** 정거장 하나 약 4분, 대장 문제 약 6분, 스테이지 하나 약 18분.
- 느린 학생이 1.3배 걸려도 75분 안에 엔딩을 본다.
- 스테이지는 **순서대로 열린다**. 앞 스테이지의 대장 문제를 끝내면 다음 스테이지가 열린다.
- 정거장도 순서대로 열린다. 끝낸 정거장은 언제든 다시 할 수 있다.

## 4. 난이도 체계

### 4.1 단계

| 단계 | 표시 | 문제 모습 | 답하는 방식 | 문제 수 |
|---|---|---|---|---|
| 1 | 🌱 씨앗 | 물건을 직접 옮기며 풀기 | 조작한 뒤 보기 3개 중 고르기 | 3 |
| 2 | 🌿 새싹 | 그림만 보고 풀기 | 보기 3개 중 고르기 | 4 |
| 3 | 🌳 나무 | 식만 보고 풀기 | 숫자판으로 입력 | 4 |
| 4 | 🍎 열매 | 빈칸 위치가 바뀜, 이야기 문제, 두 걸음 문제 | 숫자판으로 입력 | 4 |
| ★ | 히든 | 답이 여러 개, 규칙 찾기, 최소 명령 찾기 | 자유 | 스테이지별 1개 |

- 화면에는 숫자 대신 **식물 그림과 이름**만 보인다.
- 씨앗 단계는 조작에 시간이 더 걸리므로 문제를 3개만 낸다. 그래서 단계마다 걸리는 시간이 비슷하다.

### 4.2 단계 고르기와 권유
- 정거장을 시작할 때 단계 버튼 4개가 나온다. **학생이 고른다.**
- 추천 단계에 반짝임 표시를 한다.
  - 첫 정거장: 🌿 새싹
  - 그다음: 바로 앞 정거장과 같은 단계
  - 앞 정거장에서 모든 문제를 첫 시도에 맞혔으면: 한 단계 위를 추천
  - 앞 정거장에서 풀이를 2번 이상 봤으면: 한 단계 아래를 추천
- 강제로 바꾸지 않는다.

### 4.3 틀렸을 때
1. 첫 번째 오답: "다시 해 볼까요?"라는 말과 함께 부드러운 효과음. 나무·열매 단계는 그 스테이지의 전략 도구 힌트가 자동으로 열린다.
2. 두 번째 오답: 풀이 애니메이션을 보여 주고 정답을 읽어 준 뒤 다음 문제로 넘어간다.
3. 벌점, 생명, 시간 제한 없음. 한 문제에서 최대 2번만 틀릴 수 있으므로 정거장에 갇히지 않는다.

## 5. 스테이지 상세

### 공통 규칙
- 문제는 아래 범위 안에서 **무작위로 만든다**. 같은 정거장에서 같은 문제가 연속으로 나오지 않게 한다.
- 문제는 자동으로 소리 내어 읽고, 🔊 버튼으로 다시 들을 수 있다.
- 학생에게 보이는 말에는 '받아올림', '받아내림'을 쓰지 않는다. "10을 만들어요", "묶음을 풀어요"라고 쓴다.
- 조작 대상(10칸 틀, 열매 점, 상자, 달걀, 달걀판, 수직선, 100판)은 **코드로 그린다(SVG)**. 개수를 정확히 세야 하기 때문이다. GPT 그림은 배경, 캐릭터, 아이템에만 쓴다.
- 끌어 놓기가 어려운 학생을 위해 **눌러서 옮기기**도 지원한다. 물건을 한 번 누르고 놓을 곳을 누르면 옮겨진다.

### 5.1 스테이지 1 — 열매 과수원 (덧셈과 뺄셈(1))

동료: 다람쥐 토리 · 전략 도구: **10칸 틀 안경** (정거장 ①을 끝내면 받음)

**정거장 ① 열매 기차 — 세 수의 덧셈과 뺄셈** (교과서 2·3차시)

| 단계 | 문제 |
|---|---|
| 🌱 | 기차 칸에 역마다 열매를 실어(덧셈) 또는 내려(뺄셈) 본 뒤 모두 몇 개인지 고르기. 덧셈 합 6 이하, 뺄셈 처음 수 6 이하 |
| 🌿 | 열매 묶음 그림 세 개를 보고 고르기. 합 9 이하 |
| 🌳 | `3 + 2 + 4 = □`, `9 − 3 − 2 = □` |
| 🍎 | `2 + □ + 3 = 8` 같은 빈칸 문제, 이야기 문제 |

- 범위: 덧셈은 각 수 1~5, 합 9 이하. 뺄셈은 처음 수 5~9, 결과 0 이상. 덧셈과 뺄셈을 절반씩 낸다.
- 이야기 문제 예: "토리가 열매를 3개, 2개, 4개 땄어요. 모두 몇 개일까요?"

**정거장 ② 바구니 채우기 — 10이 되는 더하기, 10에서 빼기** (4~6차시)

| 단계 | 문제 |
|---|---|
| 🌱 | 10칸 바구니에 열매가 a개 있음. 빈칸이 다 찰 때까지 열매를 옮긴 뒤 몇 개를 넣었는지 고르기. 10에서 빼기는 꽉 찬 바구니에서 열매를 눌러 날려 보내기 |
| 🌿 | 10칸 틀 그림을 보고 고르기 |
| 🌳 | `7 + □ = 10`, `10 − 4 = □` |
| 🍎 | `□ + 3 = 10`, `10 − □ = 6`, 또는 **10 짝꿍 카드**: 카드 8장을 뒤집어 더해서 10이 되는 짝 4쌍 찾기 (1문제로 센다) |

- 범위: a는 1~9.

**정거장 ③ 10 올가미 — 10을 만들어 더하기** (7~8차시)

| 단계 | 문제 |
|---|---|
| 🌱 | 열매 묶음 세 개. 합이 10이 되는 두 묶음을 차례로 누르면 바구니 하나로 합쳐짐. 남은 묶음을 더해 답 고르기. 10이 되는 두 수는 항상 앞쪽에 있음 |
| 🌿 | 그림. 10이 되는 두 수의 위치가 바뀜 (앞, 뒤, 양 끝) |
| 🌳 | `6 + 4 + 3 = □`. 식에서 10이 되는 두 수를 먼저 눌러 묶은 뒤 답 입력 |
| 🍎 | 순서가 섞인 식, `6 + □ + 3 = 13` 같은 빈칸 문제 |

- 범위: 세 수 중 두 수의 합이 10, 나머지 수는 1~9, 답은 11~19.

**대장 문제: 두더지 두디의 주사위 10 만들기** (10차시 '수학이랑 만들어요')
- 두디가 주사위를 굴리면 학생이 10을 완성한다. 3판을 이기면 클리어.

| 단계 | 문제 |
|---|---|
| 🌱 | 주사위 1개. 10칸 틀에 눈의 수만큼 열매가 놓임. 10이 되려면 몇 개 더 필요한지 고르기 |
| 🌿 | 주사위 1개, 그림 없이 고르기 |
| 🌳 | 주사위 2개 (합 9 이하가 나오게 함). `□`를 입력해 10 완성 |
| 🍎 | 주사위 2개 (합 2~12). 숫자 카드 0~9 중 하나를 골라 10 완성. 두 주사위 합이 10을 넘으면 **"만들 수 없어요"** 버튼이 정답 |

### 5.2 스테이지 2 — 택배 마을 (덧셈과 뺄셈(2))

동료: 고슴도치 고미 · 전략 도구: **개구리 점프 신발** (수직선 위에서 10까지 먼저 뛰고 나머지를 뛰는 힌트)

**정거장 ① 트럭 먼저 채우기 — (몇)+(몇)=(십몇)** (2~4차시)

| 단계 | 문제 |
|---|---|
| 🌱 | 10칸 트럭 두 대. 첫 트럭에 a개가 실려 있음. 상자 b개를 옮기면 **첫 트럭부터 채워짐**. 꽉 차면 트럭이 "10!" 하고 출발. 남은 상자를 보고 답 고르기 |
| 🌿 | 10칸 틀 두 개 그림을 보고 고르기 |
| 🌳 | `8 + 5 = □` |
| 🍎 | `3 + 9 = □`처럼 작은 수가 앞, `8 + □ = 13`, 이야기 문제 |

- 범위: a, b는 2~9, 합은 11~18. 🌱은 a 7~9, b 2~5로 옮길 개수를 줄인다.
- 이야기 문제 예: "상자 8개가 있었는데 5개가 더 왔어요. 모두 몇 개일까요?"

**정거장 ② 상자 뜯기 — (십몇)−(몇)** (6~8차시)

| 단계 | 문제 |
|---|---|
| 🌱 | 10묶음 상자 1개와 낱개 몇 개. 낱개를 먼저 꺼내고, 모자라면 **'묶음 풀기'** 버튼을 눌러 10칸으로 펼친 뒤 계속 꺼내기. 남은 개수 고르기 |
| 🌿 | 그림을 보고 고르기 |
| 🌳 | `13 − 8 = □` |
| 🍎 | `13 − □ = 5`, 이야기 문제 |

- 범위: 처음 수 m은 11~18, 빼는 수 s는 2~9. **m의 일의 자리 < s** (꼭 묶음을 풀어야 하는 문제). 결과는 2 이상. 🌱은 s 5 이하.
- 풀이 애니메이션은 두 방법 중 하나를 무작위로 보여 준다: ① 10에서 빼고 남은 수 더하기, ② 낱개를 먼저 빼고 나머지 빼기.

**정거장 ③ 덧셈표 퍼즐 — 여러 가지 덧셈과 뺄셈** (5·9차시)

| 단계 | 문제 |
|---|---|
| 🌱 | 덧셈표 가로 한 줄 3칸, 빈칸 1개. 칸 사이에 "1씩 커져요" 화살표 표시 |
| 🌿 | 가로 한 줄 3칸, 빈칸 2개 |
| 🌳 | 3×3 덧셈표 조각, 빈칸 3개 |
| 🍎 | 3×3 뺄셈표 조각 빈칸 4개, 또는 "답이 같은 칸을 모두 눌러요" (대각선 규칙 찾기) |

- 범위: 표의 머리 수 1~9, 합 18 이하. 뺄셈표는 빼지는 수 11~18, 빼는 수 2~9.
- 빈칸 하나를 맞힐 때마다 칸이 채워지고, 표 전체를 다 채우면 1문제로 센다.

**대장 문제: 덧셈과 뺄셈 길 만들기** (11차시 '수학이랑 만들어요')
- 격자 칸마다 식이 적혀 있다. **답이 목표 수(예: 12)인 칸만** 밟아 출발(왼쪽 위)에서 집(오른쪽 아래)까지 간다. 지도 2장을 끝내면 클리어.
- 칸을 누를 때마다 바로 옆 칸(위·아래·왼쪽·오른쪽)만 밟을 수 있다.
- 답이 다른 칸을 누르면 트럭이 "덜컹" 하고 그 칸의 답을 보여 준 뒤 원래 자리로 돌아온다. 오답 2번 규칙은 지도 1장 단위로 적용하지 않고, 칸마다 바로 알려 주기만 한다.

| 단계 | 격자 | 식 |
|---|---|---|
| 🌱 | 3×3 | 덧셈만. 칸을 길게 누르면 10칸 틀 그림 힌트 |
| 🌿 | 3×3 | 덧셈과 뺄셈 섞임 |
| 🌳 | 4×4 | 덧셈과 뺄셈 섞임 |
| 🍎 | 4×4 | 섞임, 길 아닌 칸의 답이 목표 수 ±1로 헷갈리게 |

- 만들기: 출발에서 집까지 오른쪽·아래로만 가는 길을 무작위로 만든다. 길 위 칸에는 답이 목표 수인 식을, 나머지 칸에는 답이 목표 수가 아닌 식(목표 ±1~3)을 넣는다. 목표 수는 11~18. 식은 정거장 ①②의 범위를 따른다.

### 5.3 스테이지 3 — 달걀 가게 (덧셈과 뺄셈(3))

동료: 닭 꼬꼬 · 전략 도구: **달걀판 돋보기** (식의 수를 달걀판 10묶음과 낱개 그림으로 바꿔 보여 줌)

**정거장 ① 주문 포장 — 두 자리 수 덧셈** (2~3차시)

| 단계 | 문제 |
|---|---|
| 🌱 | 달걀판 칸과 낱개 칸이 따로 있는 상자. 주문대로 달걀판과 낱개를 옮긴 뒤 모두 몇 개인지 고르기. `30 + 4`, `23 + 4` 꼴 |
| 🌿 | 달걀판·낱개 그림을 보고 고르기. `30 + 20`, `23 + 14`, `25 + 3` 꼴 |
| 🌳 | `32 + 25 = □` |
| 🍎 | `32 + □ = 57`, 이야기 문제 |

- 범위: (몇십)+(몇), (몇십몇)+(몇), (몇십)+(몇십), (몇십몇)+(몇십몇). **일의 자리끼리 합이 9 이하**, 합 99 이하.

**정거장 ② 달걀 팔기 — 두 자리 수 뺄셈** (4~5차시)

| 단계 | 문제 |
|---|---|
| 🌱 | 달걀판과 낱개를 눌러 손님에게 건넨 뒤 남은 개수 고르기. `27 − 5`, `40 − 20` 꼴 |
| 🌿 | 그림을 보고 고르기. `38 − 12` 꼴 |
| 🌳 | `47 − 23 = □` |
| 🍎 | `58 − □ = 31`, 이야기 문제 |

- 범위: **일의 자리끼리 뺄 수 있는 문제만** (빼지는 수의 일의 자리 ≥ 빼는 수의 일의 자리). 결과 1 이상.
- 이야기 문제 예: "달걀이 35개 있어요. 손님이 12개를 사 갔어요. 몇 개 남았을까요?"

**정거장 ③ 바쁜 가게 — 덧셈과 뺄셈 섞인 주문** (6~7차시)

| 단계 | 문제 |
|---|---|
| 🌱 | 손님 말을 듣고 ＋인지 −인지만 고르기. 그다음 달걀판 그림으로 답 고르기 |
| 🌿 | ＋/− 고르기 + 그림 보고 답 고르기 |
| 🌳 | ＋/− 골라 식을 완성한 뒤 답 입력 |
| 🍎 | 두 걸음 문제: "달걀 35개가 있었어요. 12개를 팔고, 10개가 더 들어왔어요. 지금 몇 개일까요?" |

- 손님 말 예: "달걀 12개 더 주세요!"(가게 달걀이 줄어듦 → −), "달걀 20개를 가져왔어요."(늘어남 → ＋).
- 범위는 정거장 ①②와 같다. 두 걸음 문제는 중간 결과도 받아올림·받아내림이 없게 만든다.

**대장 문제: 배달 로봇 명령어** (9차시 '수학이랑 만들어요')
- 1~100이 10줄로 놓인 100판. 로봇이 시작 수에 있고, 목적지 수에 달걀빵을 배달해야 한다.
- 명령 카드: `+1`(오른쪽 한 칸), `−1`(왼쪽 한 칸), `+10`(아래 한 줄), `−10`(위 한 줄).
- 학생이 카드를 최대 8장 늘어놓고 **출발**을 누르면 로봇이 한 칸씩 움직이며 지나는 수를 읽어 준다.
- 판 밖으로 나가거나 줄 끝을 넘어가는 이동(예: 30에서 `+1`)은 "벽이에요!" 하고 멈춘다.
- 도착하면 식으로 보여 준다. 예: `23 + 10 + 10 + 10 = 53`.
- 실패해도 벌점 없이 카드를 고쳐 다시 출발할 수 있다. 2번 실패하면 다음 카드 방향을 화살표로 알려 준다. 3판을 끝내면 클리어.

| 단계 | 문제 |
|---|---|
| 🌱 | `+10`만 쓰면 되는 문제 (23 → 53) |
| 🌿 | `+10`과 `+1` (23 → 45) |
| 🌳 | 네 카드 모두 (47 → 25) |
| 🍎 | 구덩이 칸 2~3개를 피해 가기. 카드 수 제한 = 최소 카드 수 + 2 |

## 6. 보상 체계

### 6.1 열매(화폐)
| 행동 | 열매 |
|---|---|
| 첫 시도에 정답 | +2 |
| 다시 해서 정답 | +1 |
| 풀이를 보고 넘어감 | 0 |
| **도전 보너스**: 이 학생이 지금까지 고른 가장 높은 단계보다 높은 단계로 정거장을 끝냄 | +5와 '도전 배지' 스티커 |
| 🍎 열매 단계로 정거장을 끝냄 | 황금 열매 1개 |

- 도전 보너스는 **절대 단계가 아니라 그 학생 자신의 이전 기록**을 기준으로 한다. 씨앗 → 새싹으로 올라간 학생도, 나무 → 열매로 올라간 학생도 똑같이 받는다.
- 전략 도구 힌트는 써도 열매가 줄지 않는다.

### 6.2 동료 캐릭터 성장
- 스테이지를 시작하면 동료가 **아기** 모습으로 나온다.
- 정거장 ②를 끝내면 **자람**, 대장 문제를 끝내면 **어른**이 된다.
- 성장은 단계와 상관없이 정거장을 끝내기만 하면 된다.

### 6.3 전략 도구
| 도구 | 받는 때 | 효과 (🌳·🍎 단계에서 버튼으로 사용) |
|---|---|---|
| 10칸 틀 안경 | 스테이지 1 정거장 ① 완료 | 식의 수를 10칸 틀 그림으로 보여 줌 |
| 개구리 점프 신발 | 스테이지 2 정거장 ① 완료 | 수직선 위에서 10까지 먼저 뛰고 나머지를 뛰는 그림 |
| 달걀판 돋보기 | 스테이지 3 정거장 ① 완료 | 수를 달걀판 10묶음과 낱개로 보여 줌 |

- 처음 받을 때 "멋진 도구를 얻었어요!" 연출. 도구는 화면 오른쪽 아래 도구 칸에 놓인다.

### 6.4 쉼터와 꾸미기
- 스테이지 1이 끝난 뒤, 그리고 엔딩 뒤에 '쉼터'가 열린다.
- 열매로 톡이의 꾸미기 아이템을 산다. 산 아이템은 지도와 엔딩에서 톡이에게 입혀진다.
- 쉼터는 **1분 안에 끝나도록** 상품을 6개로 제한하고, "다 골랐어요" 버튼을 크게 둔다.

| 아이템 | 값 |
|---|---|
| 밀짚모자 | 열매 5 |
| 리본 | 열매 5 |
| 꽃 화분 | 열매 8 |
| 무지개 우산 | 열매 8 |
| 별 망토 | 황금 열매 1 |
| 왕관 | 황금 열매 2 |

### 6.5 히든 요소
**10 조각** (스테이지마다 1개, 단계와 상관없이 누구나 찾을 수 있음)
| 조각 | 나타나는 조건 | 찾는 법 |
|---|---|---|
| 조각 1 | 스테이지 1 정거장 ②를 끝낸 뒤 | 과수원 지도에서 은은하게 반짝이는 나무를 누름 |
| 조각 2 | 스테이지 2 정거장 ②를 끝낸 뒤 | 택배 마을 지도의 우체통을 누름 |
| 조각 3 | 스테이지 3 정거장 ②를 끝낸 뒤 | 달걀 가게 지도의 열 번째 달걀 바구니를 누름 |

- 반짝임은 약하게 시작해서, 엔딩까지 못 찾았으면 엔딩 뒤 지도에서 더 밝아진다.

**히든 친구 열이**: 조각 3개를 모두 모으고 엔딩을 보면 나타나 도감에 들어간다. 못 모았으면 엔딩에 그림자 모습과 "숨은 친구가 있어요" 한 줄이 나온다.

**히든 단계 ★** (엔딩 뒤, 그 스테이지의 10 조각을 가진 학생에게 열림)
| 스테이지 | 히든 단계 | 내용 |
|---|---|---|
| 1 | 13 만들기 대회 | 숫자 카드 1~9 중 세 장으로 합 13 만들기. 서로 다른 조합 3개를 찾으면 클리어 |
| 2 | 같은 답 모으기 | 식 카드 8장 중 답이 13인 식을 모두 찾기. 정답 식 3~4장(예: 8+5, 9+4, 7+6, 17−4)과 답이 12·14인 식을 섞는다. 식은 정거장 ①② 범위만 쓴다 |
| 3 | 가장 짧은 배달 | 로봇 명령어를 **가장 적은 카드**로 도착하기. 최소 카드로 성공하면 왕관 표시 |

- 히든 단계를 끝내면 황금 열매 2개.

**숨은 업적** (미리 알려 주지 않고, 이루면 깜짝 공개)
- 답이 10인 문제 10개 풀기
- 한 정거장을 모든 문제 첫 시도로 끝내기
- 세 동료를 모두 어른으로 키우기
- 꾸미기 아이템 4개 모으기

### 6.6 도감
- 동료 3명 + 열이, 전략 도구 3개, 꾸미기 6개, 숨은 업적 4개를 한 화면에 보여 준다.
- 못 모은 칸은 회색 그림자로 둔다.

## 7. 화면과 기능 요구사항

### 7.1 화면 목록
| 화면 | 내용 |
|---|---|
| 반·번호 | 반 버튼 1~10, 번호 버튼 1~30. "3반 12번 맞아요?" 확인. 이 태블릿에 저장된 반·번호를 '최근' 버튼으로 보여 줌 |
| 프롤로그 | 그림 3컷, 자동 읽기, 건너뛰기 버튼 |
| 마을 지도 | 스테이지 3개와 정거장, 톡이와 동료, 열매 수, 도구 칸, 도감 버튼 |
| 단계 고르기 | 식물 버튼 4개, 추천 반짝임 |
| 문제 | 문제 그림·식, 🔊 버튼, 보기 또는 숫자판, 도구 버튼, 진행 점 (●●○○) |
| 정거장 결과 | 받은 열매, 도전 보너스, 동료 성장 연출 |
| 쉼터 | 꾸미기 상점 |
| 쉬는 시간 | 스테이지 2가 끝나면 "1교시 끝! 쉬는 시간이에요". **"2교시 시작" 버튼을 2초 길게 눌러야** 넘어감 |
| 엔딩 | 축제 장면, 동료 셋, 열이(조건부), 도감 |
| 교사 메뉴 | 반·번호 화면 제목을 5번 연속 누르고 숫자 `1010` 입력 |

### 7.2 교사 메뉴
- 이 학생 기록 지우기
- 이 태블릿의 모든 기록 지우기 (한 번 더 확인)
- 모든 스테이지 열기 (단원별 수업이나 시연용)
- 소리 켜기/끄기, 음성 읽기 켜기/끄기

### 7.3 입력과 화면
- **가로 화면 고정.** 세로로 들면 "태블릿을 옆으로 돌려 주세요" 안내.
- 기준 화면 1280×800, 기기 크기에 맞춰 비율 유지하며 확대·축소 (남는 곳은 배경색).
- 버튼 최소 64×64px, 숫자판 버튼 80×80px 이상.
- 문제 글자 32px 이상, 식의 숫자 64px 이상.
- 학생 문장은 존댓말 한 문장, 20자 안팎. 예: "바구니를 채워 볼까요?"
- 끌어 놓기는 포인터 이벤트로 만들고, 가까이 놓으면 자석처럼 칸에 붙는다. 눌러서 옮기기도 지원.
- 길게 누르기 메뉴, 글자 선택, 당겨서 새로고침, 확대 제스처를 막는다.
- 시작 버튼을 누르면 전체 화면으로 전환한다 (지원할 때만).

### 7.4 소리
- 음성 읽기: 브라우저 내장 음성(`speechSynthesis`)의 한국어 목소리, 속도 0.9. 첫 터치 뒤에만 켠다. 한국어 목소리가 없으면 🔊 버튼을 숨기고 글자로만 진행한다.
- 효과음: Web Audio로 코드에서 만든다 (정답, 오답, 트럭 출발, 단계 올리기, 아이템 얻기). 파일을 쓰지 않는다.
- 배경 음악 없음.

### 7.5 저장
- 브라우저 저장소(`localStorage`)에 반·번호별로 저장한다. 키: `yeolmae_v1:{반}-{번호}`.
- 저장 내용: 열린 스테이지·정거장, 정거장별 최고 단계, 열매·황금 열매, 도구, 꾸미기와 착용 상태, 10 조각, 업적, 동료 성장 상태, 엔딩 여부.
- **문제를 하나 풀 때마다, 그리고 정거장을 끝낼 때마다** 저장한다. 새로고침하거나 쉬는 시간 뒤에도 그 정거장 처음부터 이어 한다.
- 저장소를 쓸 수 없으면 메모리로 진행하고 교사 메뉴에 "저장이 안 되는 상태" 표시.

### 7.6 파일과 배포
```
yeolmae-village/
├── index.html          ← 코드 전부 (HTML, CSS, JS 한 파일)
└── assets/
    ├── bg/             ← 배경
    ├── char/           ← 캐릭터
    └── item/           ← 아이템
```
- 외부 라이브러리, 외부 폰트를 쓰지 않는다. 글꼴은 기기 기본 글꼴.
- 그림은 WebP. 배경 300KB 이하, 캐릭터·아이템 150KB 이하, **전체 4MB 이하** (25대가 동시에 열어도 빨리 뜨도록).
- 배경은 그 스테이지에 들어갈 때 불러온다. 그림을 못 불러오면 정해진 색 바탕과 도형으로 대신 그린다.
- 폴더 이름은 영어로 한다 (주소에 한글이 들어가면 QR이 길어짐).
- GitHub Pages에 올린 뒤 `https://{계정}.github.io/{저장소}/yeolmae-village/` 주소로 QR을 만든다.

# 2부. 그림 제작 프롬프트 (GPT 이미지)

## 8. 그림 만들기

### 8.1 순서
1. 스타일 고정 문구를 먼저 보낸다.
2. **톡이를 먼저** 만들고 마음에 들 때까지 고친다.
3. 마음에 든 톡이 그림을 다시 첨부하며 "이 그림과 같은 화풍으로"를 붙여 나머지를 만든다. 동료 캐릭터의 성장 3단계는 아기 그림을 첨부하고 만든다.

## 10. 검수 목록

### 10.1 수업 전 (교사가 태블릿 1대로)

## 부록. 교과서 차시와 정거장 대응

| 단원 | 교과서 차시 | 게임 |
|---|---|---|
| 2 덧셈과 뺄셈(1) | 1 단원 도입 | 프롤로그 |
| | 2 세 수의 덧셈, 3 세 수의 뺄셈 | 스테이지 1 정거장 ① |
| | 4-5 10이 되는 더하기, 6 10에서 빼기 | 정거장 ② |
| | 7-8 10을 만들어 더하기 | 정거장 ③ |
| | 9 문제 해결 | 🍎 단계 이야기 문제 |
| | 10 주사위로 10 만들기 | 대장 문제 |
| 4 덧셈과 뺄셈(2) | 1 단원 도입 | 스테이지 2 시작 장면 |
| | 2 덧셈 알아보기, 3-4 덧셈하기 | 스테이지 2 정거장 ① |
| | 5 여러 가지 덧셈, 9 여러 가지 뺄셈 | 정거장 ③ |
| | 6 뺄셈 알아보기, 7-8 뺄셈하기 | 정거장 ② |
| | 10 문제 해결 | 🍎 단계 이야기 문제 |
| | 11 덧셈과 뺄셈 길 만들기 | 대장 문제 |
| 6 덧셈과 뺄셈(3) | 1 단원 도입 | 스테이지 3 시작 장면 |
| | 2-3 덧셈 알아보기 | 스테이지 3 정거장 ① |
| | 4-5 뺄셈 알아보기 | 정거장 ② |
| | 6-7 덧셈과 뺄셈 | 정거장 ③ |
| | 8 문제 해결 | 🍎 단계 이야기 문제 |
| | 9 명령어 만들기 | 대장 문제 |

> 정거장 ②③의 세부 내용 중 일부(4단원 5·9차시, 6단원 2~7차시)는 차시 제목으로 추정했습니다. 과정안과 다르면 5장의 범위 표만 고치면 됩니다.
