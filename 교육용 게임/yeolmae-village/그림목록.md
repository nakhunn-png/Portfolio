# 열매 마을 축제: 필요한 그림

그림이 없어도 게임은 돌아갑니다. 그림이 없는 자리에는 이모지가 대신 나옵니다.
그림 파일을 아래 이름 그대로 `assets/` 폴더에 넣으면 그 자리만 그림으로 바뀝니다.

- 파일 형식: **PNG 또는 WebP** 둘 다 됩니다. GPT가 준 PNG를 이름만 바꿔 넣으면 됩니다.
- 캐릭터·아이템은 **투명 배경**으로 받으세요.
- 용량을 줄이려면 WebP로 바꾸세요(품질 80 정도). 학생 25명이 동시에 열 때 빨리 뜹니다.

## GPT에 먼저 보낼 스타일 문구

```
[스타일] 초등학교 1학년용 그림책 같은 일러스트. 둥글고 부드러운 형태, 따뜻한 파스텔 색(복숭아색, 연두, 하늘색, 버터 노랑), 은은한 그림자, 단순한 형태.
굵은 검은 외곽선 없음. 무섭거나 날카로운 요소 없음. 사진풍 아님.
이미지 안에 글자, 숫자, 로고를 절대 넣지 말 것.
```

**순서**: 톡이를 먼저 만들고, 마음에 들면 그 그림을 첨부하며 "이 그림과 같은 화풍으로"를 붙여 나머지를 만드세요. 동료의 자란 모습(2, 3)은 아기 그림(1)을 첨부해서 만드세요.

## 실행과 배포

- **내 컴퓨터에서 보기**: `yeolmae-village` 폴더에서 `python -m http.server 5173`을 실행하고 브라우저로 `http://localhost:5173`을 엽니다. `index.html`을 더블클릭해도 대부분 동작합니다.
- **학생 배포**: `yeolmae-village` 폴더를 GitHub Pages에 올리고, 그 주소로 QR을 만듭니다.
- **선생님 메뉴**: 첫 화면의 "열매 마을 축제" 글자를 5번 빠르게 누르고 `1010`을 입력합니다. 소리·음성 끄기, 학생 기록 지우기, 모든 스테이지 열기, 문제 범위 검사가 있습니다.
