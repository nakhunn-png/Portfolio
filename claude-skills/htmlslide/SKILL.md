# htmlslide: 편집되는 HTML 슬라이드 덱

사용자가 준 내용으로 **자기완결 HTML 한 파일**을 만든다. 외부 의존은 폰트 CDN 하나(Pretendard)뿐이다. 기존 덱이 첨부되면 그 구조·테마를 그대로 따르고 내용만 바꾼다.

## 해상도: 만들기 전에 먼저 묻는다

- 작업을 시작하기 전에 AskUserQuestion으로 **1920×1080(Full HD)** 과 **3840×2160(4K)** 중 어느 쪽으로 만들지 묻는다. 사용자가 이미 말했으면 묻지 않는다.
- 사용자가 자리에 없거나 답이 없으면 1920×1080으로 진행하고, 첫 줄에 그렇게 정했다고 밝힌다.
- 디자인 캔버스는 1920×1080 기준 하나로 짠다. 4K는 같은 레이아웃을 2배 배율(`--S: 2`)로 키워 만든다. 글자 크기·여백·위치를 따로 다시 잡지 않는다.
- 캔버스 크기는 `--W`·`--H` 변수와 JS의 `W`·`H` 상수 한 곳에서만 정한다. 해상도를 바꿀 때는 이 값만 고치면 되게 한다.
- 인쇄·PDF 쪽 크기(`@page size`)도 선택한 해상도에 맞춘다.
- 4K는 파일 크기와 렌더 부담이 커질 수 있으니 이미지·폰트를 가볍게 쓴다.

## 구조

- 캔버스는 선택한 해상도로 고정하고, 창 크기에 맞춰 `transform: scale`로 맞춘다.
- 슬라이드는 `<section class="slide">`. 종류: 표지, 본문(헤더+본문), 부 구분, 한 문장, 마무리.
- 색은 `:root` 토큰으로만 쓴다. 슬라이드 안에 색 리터럴을 쓰지 않는다.
- 슬라이드마다 `<aside class="notes">`에 발표자 노트를 둔다. 화면에는 숨긴다.
- 화면 글자는 1920×1080 기준 27px 이상(1280 기준 18px에 해당), 핵심 제목은 한 줄, 본문 장은 위치·크기를 고정한다.

## 발표 모드

- `←` `→` `Space`로 넘기고(`data-step`이 있으면 단계별로 공개), `Home` `End`, 터치 스와이프도 지원한다.
- `F` 전체화면, `N` 발표 노트, `G` 전체 보기(썸네일), `D` 펜(1~5 색, `Z` 되돌리기, `C` 지우기), `L` 레이저, `?` 단축키 표.
- 인쇄·PDF는 `@media print`로 한 장 = 한 쪽.
- 단축키는 `e.code`(물리 키)로 판정해 한글 입력 상태에서도 동작하게 한다.

## 편집 모드 (핵심)

- `E`키로 켜고 끈다. 켜면 텍스트 요소에 `contenteditable`을 주고 Esc로 끝낸다. 점선 윤곽으로 편집 가능 표시를 한다.
- **Ctrl+S 덮어쓰기, Ctrl+Shift+S 새 이름으로 저장.** 둘 다 `preventDefault`로 브라우저 기본 동작을 막는다.
  - 지원하면 File System Access API(`showOpenFilePicker`/`showSaveFilePicker`)를 쓴다. Ctrl+S는 처음 한 번 파일 핸들을 받은 뒤 그 파일에 덮어쓴다.
  - 지원하지 않거나 iframe 미리보기처럼 막힌 환경이면 `Blob` 다운로드로 대체하고, 화면에 "이 환경에서는 덮어쓰기가 안 돼 새 파일로 내려받았다"고 알린다.
  - 저장 성공·실패를 토스트로 보여 준다. 조용히 아무 반응이 없으면 안 된다.
- 저장본에는 실행 중에만 생기는 것(컨트롤 막대, 펜 캔버스, 푸터 주입, `contenteditable`, `.on` 클래스, 인라인 폰트 크기)을 모두 지우고 깨끗한 HTML로 직렬화한다.
- 편집으로 바뀌는 범위는 글자뿐이다. 도형 이동·슬라이드 추가·삭제·순서 변경이 필요하면 따로 요청받은 경우에만 만든다.

## 모바일 (폭 820px 이하)

- 슬라이드를 세로로 쌓아 스크롤하게 한다(`body.m`). 모든 그리드는 한 줄 한 칸, 순차 공개는 전부 펼치고, 스와이프 넘김·컨트롤·노트·펜은 끈다.
- `history.replaceState`처럼 샌드박스 뷰어에서 막히는 호출은 `try/catch`로 감싼다.
- 모바일에서는 키보드가 없으므로 편집 모드는 버튼으로 켜게 하거나 PC 전용이라고 안내한다.

## 마치기 전 확인

1. 390px 폭으로 열어 가로 넘침이 없는지, 콘솔 오류가 없는지 본다.
2. 선택한 해상도에서 제목 줄 수, 하단 넘침을 본다.
3. 편집→저장→다시 열기로 수정이 남는지 확인한다. 덮어쓰기가 안 되는 환경이면 그 사실을 사용자에게 말한다.
4. 결과는 `.html` 한 파일로 전달한다.
