# xl2claude — 엑셀을 Claude가 읽기 좋은 형태로

엑셀을 통째로 읽지 않는다. 먼저 변환하고, 요약을 읽고, 필요한 것만 SQL로 꺼낸다.

## 1. 변환
```bash
pip install -r requirements.txt   # 처음 한 번
python scripts/xl2claude.py convert "<엑셀 경로>" -o "<출력 폴더>"
```
- 100만 행 분개장 ≈ 15초, 메모리 ≈ 0.8GB
- 수식이 필요 없으면 `--no-formulas`, 작은 표도 DB로 빼려면 `--table-min 20`

## 2. 읽는 순서
1. `<출력>/INDEX.md` — 시트 목록, 유형(서식형/데이터 표), 크기, 파일 위치
2. 필요한 `sheets/NN_시트명.md`만 읽는다
   - **서식형**(조서·주석·총괄표): 셀 값 그대로. `값[=수식]`, `[=↑]` = 위 셀과 같은 수식
   - **데이터 표**(분개장·raw): 열 프로필(유형·합계·최소/최대·상위값), 미리보기, 자동 요약
     - 차변/대변 열이 있으면: 차대 합계 검증, 전표별 불일치, 월별·계정별 집계
     - 그 밖의 표: 범주 열별 금액 합계
   - 표 데이터가 다른 시트와 똑같으면 "중복"으로 표시만 하고 다시 쓰지 않는다
3. 세부가 필요하면 원본을 열지 말고 DB를 조회한다

## 3. 조회
```bash
python scripts/xl2claude.py schema "<출력>"
python scripts/xl2claude.py query "<출력>" "SELECT 계정과목, SUM(차변) FROM t_분개장 GROUP BY 1"
```
- 출력은 TSV, 기본 200행까지(`--max`로 조정). 행 단위로 뽑기보다 GROUP BY·WHERE로 줄여서 본다
- `_row` 열 = 원본 엑셀 행 번호. 답변에서 근거 위치를 말할 때 쓴다
- 테이블 이름은 `t_<시트명>`(특수문자는 `_`), 열 이름은 시트 md의 열 프로필 `DB이름` 열 참고

## 한계
- 셀 서식(색·테두리)·메모·차트·피벗 정의는 읽지 않는다. 값과 수식만
- 다단 머리글은 가장 아랫줄을 열 이름으로 쓰고, 윗줄은 '표 바깥 셀'에 남긴다
- 엑셀 한 시트는 최대 1,048,576행이므로 그보다 큰 분개장은 CSV로 받아 변환한다
