- 글에 쓰는 표현 예

  - 회계 실무는 "곧 하게 될 일", "수습 들어가기 전에" 처럼 앞으로의 일로
- 쓰지 않는 것: 실명, 학교명·지역, 학년·반 등 학교·학생 특정 정보, 발급번호·주민번호
  - 합격사실확인서 같은 서류는 성명·발급번호·주민번호를 모자이크한 뒤에만 사용
  - **관심 부동산(실제로 살고 싶은 집 — 구체적인 단지명은 작업 폴더 docs/PLAN.md에만 기록) 이름·단지번호·매물 화면은 노출 금지** — 다른 단지 예시로 대체하거나 모자이크
  - 합격 연도·회차는 확인서 사진에 보이는 정도까지만, 본문에서 따로 강조하지 않음
- 말투 (2026-10-23 사용자 지시로 변경 — 일기체가 "AI 어투"로 보인다는 피드백):
  - **불특정 다수에게 말하는 구어체 존댓말.** 레퍼런스: [meetcpa 블로그](https://blog.naver.com/meetcpa/224402177289) (`research/meetcpa_224402177289.txt`)
  - 끝맺음: ~했습니다 / ~했어요 / ~거든요 / ~더라구요 / ~죠 / ~하려고 합니다 / ~것 같습니다
  - 가벼운 혼잣말·감탄: "ㅎㅎ", "😅", "..", "아마도..?", "요렇게", 문장 끝 "!"
  - **쓰지 않는 것 (AI 티 나는 표현):** 문학적 장면 묘사("칠판의 분필 자국을 지우다 문득"), 경구·명언형 문장("~가 없으면 그건 ~가 아니다"), "교실과 회계 사이 어딘가" 같은 은유, "오늘도 수고했다, 나 자신" 같은 일기 마무리, 대구·삼단 나열 남발
  - 사실 위주로: 무엇을 했고, 무엇이 어려웠고, 무엇을 하려는지
- **두 번째 레퍼런스 (2026-10-24 추가):** [후천적 재능러 「회계사 2년차,,, 이제 이직 할 때인가?」](https://blog.naver.com/7soccernim7/224038684963) (`research/7soccernim7_224038684963.raw.txt`)
  - 성격: meetcpa가 **정보 공유형**이라면 이쪽은 **솔직한 소회·고민형**. 이미지·인용구 없이 문장만으로 흐름을 만든다
  - **역할 분담:** 정보·방법·검증 섹션 = meetcpa 방식 / **도입·고민·소회·마무리 = 이 레퍼런스 방식**
  - 가져올 특징:
    - 자극적인 제목 뒤 첫 줄에 셀프 인정 훅 ("어그로 좀 끌어봤습니다." 같은 느낌을 **우리 말로 새로 써서**)
    - 근황으로 시작: "어느덧 ~가 됐다", "~느라 정신없었다"
    - **쉼표 말줄임 `,,` `,,,`** 를 한숨처럼 — 제목에 1번까지, 본문 회당 2~4번 (남발 금지)
    - 질문 화법: "~냐고 물어본다면 / ~같습니다", "~하지 않았을까? 라고 기대했습니다만"
    - **기대 vs 현실 솔직 고백**: "~할 줄 알았는데 너무 순진한 생각이었습니다", "실상은 ~더라구요,,"
    - 일반론 → 내 경우 → 다른 분께 한마디 순서, 단정 대신 "~라 생각합니다 / ~거 같습니다"
    - 마무리는 짧은 줄 3~4개로 다짐 ("그게 뭐가 됐든 / 뭐라도 해야 / ~니까요.")
  - 가져오지 않을 것: 문장·표현을 그대로 베끼기, 닉네임("후천적 재능러")·회사 생활 설정
- 줄 바꿈:
  - 정보 섹션 (meetcpa): **한 줄에 한 호흡(15~25자)**, 2~4줄을 한 문단으로 묶고 문단 사이 빈 줄 (문단 안 `<br>`, 문단은 `<p>`)
  - 소회 섹션 (후천적 재능러): **한 문장 = 한 문단** (`<p>` 하나에 한 문장 → 문장마다 빈 줄 자동). 섹션이 바뀔 때는 `<p><br></p>` 1~2개를 더 넣어 여백을 크게
- 교사 출신 정체성은 사실로만: "1학년 아이들한테 매일 하는 말", "수업 지도안 짜듯"
- 태도: AI가 무섭기도 하고 신기하기도 한 초보. 아는 척하지 않고 틀린 것도 솔직히 기록
- 회계 내용은 정확하게, AI 답변은 "그대로 믿으면 안 된다"는 검증 습관을 꼭 보여줌
